# 05-stage2-input-brief.md

## 项目名称

悦享互动宝

## 一句话定位

悦享互动宝是一个面向泛娱乐和轻量工具用户的微信小程序，通过视频提取、影视福利、互动小游戏和积分任务，为用户提供工具与资源权益，并通过广告、会员和邀请实现商业化变现。

阶段性定位：

> 工具入口 + 影视福利 + 互动积分任务的微信小程序。

## MVP 目标

当前 MVP 的唯一目标是：

> 验证“工具/影视入口 + 积分任务 + 会员权益 + 邀请裂变”是否能带来有效用户、广告收益、会员转化和次日留存。

MVP 要验证的问题：

1. 用户是否愿意通过视频下载、影视资源或小游戏进入小程序。
2. 用户是否愿意完成签到、小游戏、广告加倍等积分任务。
3. 用户是否理解并接受统一积分体系。
4. 用户是否愿意为了更多积分任务、提现权益、高清资源或邀请奖励开通会员。
5. 用户是否愿意邀请好友来解锁资源或获得积分。
6. 激励广告 eCPM、广告完成率、提现成本、会员收入之间是否能形成可持续模型。

## 目标用户

### 核心用户

1. 泛娱乐资源用户
   - 需要影视资源、番剧资源、最新电影、高清/4K 网盘资源。
   - 愿意通过完成互动、观看广告或邀请好友解锁资源。

2. 积分福利用户
   - 对签到、小游戏、积分任务、提现、兑换、邀请奖励感兴趣。
   - 包括大学生、普通微信群用户、碎片时间用户、轻度羊毛用户。

3. 短视频工具用户
   - 需要视频链接解析、短视频下载、素材保存。
   - 包括短视频创作者、自媒体运营者、剪辑用户。

### 非当前优先用户

1. 专业股票/金融用户。
2. 车主刚需用户。
3. 重度游戏玩家。
4. 大规模羊毛群用户。

## 核心功能

### 1. 统一积分体系

所有用户激励前台统一表现为“积分”。

积分来源：

- 每日签到。
- 玩小游戏。
- 看广告加倍。
- 邀请好友。
- 好友开通会员返积分。
- 开通会员赠积分。
- 影视/下载相关任务。

积分用途：

- 提现。
- 兑换影视高清权益。
- 兑换视频下载免广告次数。
- 兑换游戏额外次数。
- 兑换提现手续费减免券。
- 兑换会员优惠券。

后台需要区分：

- 总积分。
- 可提现积分。
- 冻结积分。
- 消耗积分。
- 已提现积分。

前台不展示复杂账户，只展示用户能理解的积分、可兑换金额、可提现积分和冻结积分。

### 2. 签到积分

功能范围：

- 每日签到得积分。
- 看广告可翻倍。
- 连续 3 天/7 天签到额外奖励。
- 会员签到积分加成。

建议文案：

> 今日签到，领取积分。

> 完成互动后可获得更多积分。

### 3. 视频下载助手

功能范围：

- 用户粘贴视频分享链接或带链接的文案。
- 点击开始解析。
- 解析成功后保存到系统相册。
- 免费用户下载前需要完整观看激励广告。
- VIP 会员可直接下载或享受更多下载次数。
- 解析失败提供兜底路径。

技术现状：

- 依赖爬虫 request 逆向和 yt-dlp 补充。
- 国内多个平台支持。
- 抖音因反查严格，部分视频可能下载失败。
- 视频号因需要企业微信客服转 URL，目前尚未接入。

### 4. 影视福利

功能范围：

- 番剧片库。
- 最新电影。
- 4K 影视。
- 搜索资源。
- 复制百度网盘链接。
- 复制夸克网盘链接。
- 解锁高清/4K 权益。
- 追更提醒或加入片单。

交互规则建议：

- 免费用户完成互动或观看广告后复制资源。
- 会员用户每日可直接复制一定次数。
- 用户可消耗积分免广告复制。
- 邀请 3 人解锁高清资源。
- 邀请 5 人解锁 4K 资源。

### 5. 互动小游戏/任务中心

底部 Tab 可继续叫“游戏”，但页面定位为“互动任务中心”。

功能范围：

- 今日可得积分。
- 今日剩余互动次数。
- 已获得积分。
- 每日签到入口。
- 小游戏入口。
- 看广告加倍。
- 会员解锁更多次数。

初期游戏：

- 石头剪刀布。

后续可扩展：

- 猜数字。
- 每日答题。
- 幸运翻牌。
- 2048 简版。

### 6. 会员中心

会员权益需要明确、可感知。

建议权益：

- 更多每日积分任务。
- 签到积分加成。
- 小游戏互动次数增加。
- 提现门槛降低。
- 提现手续费减免或降低。
- 影视高清/4K 权益。
- 视频下载免广告或更多次数。
- 邀请好友奖励加成。
- 开通会员赠送积分。

当前计划价格：

- 月卡：19.9 元。
- 季卡：59.9 元。
- 年卡：239.9 元。

阶段一建议：

- 初期主推月卡和季卡。
- 年卡 239.9 元可能偏高，可后续根据数据调整为限时价或更低价格区间。

### 7. 邀请好友

功能范围：

- 展示我的邀请人数。
- 展示已获得积分。
- 邀请好友得积分。
- 邀请 3 人解锁高清资源。
- 邀请 5 人解锁 4K 资源。
- 好友开通会员返积分。
- 一键复制邀请话术。
- 一键生成分享海报或邀请码。

返利规则当前方向：

- 一级会员返利：计划 50%。
- 二级会员返利：计划 5%。
- 建议用积分形式承接返利，并设置冻结期。

### 8. 提现与收益记录

功能范围：

- 我的积分。
- 可兑换金额。
- 可提现积分。
- 冻结积分。
- 累计提现。
- 立即提现。
- 提现记录。
- 收益明细。

当前计划：

- 新人或会员可较低门槛提现。
- 提现门槛暂定 1 元。
- 单日最高提现曾考虑 100 元，但 MVP 阶段建议谨慎展示和控制。
- 提现手续费曾考虑 10%，可根据会员权益、活动和用户体验动态调整。

## 技术约束

1. 平台为微信小程序。
2. 已通过平台审核。
3. 已开通流量主。
4. 激励广告 eCPM 当前预估 40–70 元，即单次广告收入约 0.04–0.07 元。
5. 视频下载依赖 request 逆向、爬虫和 yt-dlp。
6. 抖音部分视频可能下载失败。
7. 视频号暂未接入。
8. 影视资源来自外部实时更新文档抓取，需要考虑数据格式变化和抓取失败。
9. 平台广告收益月结，积分发放和提现会带来资金垫付压力。
10. 积分、广告回调、提现必须保证账务一致性。

## 商业化

### 收入来源

1. 激励广告收入。
2. 会员收入。
3. 会员邀请返利带来的裂变增长。
4. 未来可能的积分兑换、权益包、会员升级等收入。

### 当前商业规则方向

1. 免费用户通过完成互动或观看广告获得积分、复制资源或下载权益。
2. 会员用户获得更多积分任务、更多互动次数、更低提现门槛、高清影视权益、下载权益和邀请奖励加成。
3. 邀请好友可获得积分。
4. 好友开通会员可按比例返积分。
5. 积分可提现或兑换权益。

### 会员价格

当前计划：

- 月卡：19.9 元。
- 季卡：59.9 元。
- 年卡：239.9 元。

阶段一建议：

- 主推月卡和季卡。
- 年卡价格后续根据实际转化调整。
- 避免承诺固定回本周期。

### 广告与积分模型

当前广告收益：

- eCPM：40–70 元。
- 单次广告收入：约 0.04–0.07 元。

积分奖励建议：

- 不固定高额返利。
- 根据任务类型、会员等级、广告收益、风控状态动态发放。
- 控制每日可提现积分上限。
- 增加积分消耗场景。

## 待确认问题

### 产品规则

1. 积分与金额的兑换比例最终是否确定为 100 积分 = 1 元，还是 1 积分 = 0.01 元。
2. 普通用户每日可完成多少次积分任务。
3. 会员每日可完成多少次积分任务。
4. 普通用户和会员的每日可提现上限分别是多少。
5. 签到积分、广告翻倍积分、连续签到奖励分别是多少。

### 会员规则

1. 月卡、季卡、年卡最终价格是否调整。
2. 年卡是否需要做限时价。
3. 各会员等级的每日任务次数、提现门槛、手续费、影视权益、下载权益如何区分。
4. 会员开通赠送积分是否可提现，还是仅可兑换权益。

### 邀请规则

1. 邀请注册奖励多少积分。
2. 邀请 3 人、5 人分别解锁哪些权益。
3. 好友开通会员后的一级、二级返利是否按 50% 和 5% 执行。
4. 邀请返利冻结期多久。
5. 非会员是否可以参与会员返利。

### 提现规则

1. 新人是否允许 1 元首提。
2. 后续提现门槛是多少。
3. 提现手续费是否收取 10%。
4. 会员是否免费提现或低手续费。
5. 提现是自动审核还是人工审核。
6. 提现到账周期如何展示。

### 推广规则

1. 第一批测试渠道优先选择大学生群、普通微信群、影视群还是短视频创作者群。
2. 是否准备三套不同推广话术。
3. 是否需要制作邀请海报。
4. 是否暂缓羊毛群推广。

### 后续游戏小程序

1. 是否正式立项独立游戏小程序。
2. 游戏小程序是否复用互动宝积分体系。
3. 游戏小程序首批游戏选择哪些。
4. 游戏小程序与互动宝之间如何互相导流。
5. 游戏小程序是否作为下一阶段单独进入阶段一深度讨论。
