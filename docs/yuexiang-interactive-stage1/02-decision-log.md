# 02-decision-log.md

## 决策 1：悦享互动宝继续推进，但不再定位为单一短视频下载工具

### 已确认决策

悦享互动宝继续推进，但阶段性定位从“短视频下载工具”调整为“工具入口 + 影视福利 + 互动积分任务”的微信小程序。

### 选择理由

1. 短视频下载功能竞品较多，且抖音等平台存在反查和下载失败问题，单独作为主定位不够稳。
2. 当前产品已经加入影视资源和小游戏功能，实际已经不是单一工具。
3. 视频下载可以继续作为工具入口，但不适合作为唯一主线。
4. 积分、小游戏、会员、邀请更符合项目当前“短期流量变现”的目标。

### 是否可后续调整

可调整。若后续数据显示视频下载功能带来高频使用和高会员转化，可以重新强化视频下载定位。

---

## 决策 2：首页保留视频下载，但必须增加签到/积分/任务入口

### 已确认决策

首页不再只展示“视频下载助手”，需要增加“今日福利/签到/积分任务”的首屏入口。

### 选择理由

1. 当前首页过于工具化，用户没有下载需求时会直接流失。
2. 签到和积分任务能为用户提供低门槛首个动作。
3. 首页应承担承接作用，引导用户进入影视、游戏、邀请和会员路径。

### 是否可后续调整

可调整。若后续推广主力来自视频下载用户，可提高视频下载模块权重；若来自影视或积分用户，则继续强化福利入口。

---

## 决策 3：前台统一使用“积分”概念

### 已确认决策

用户前台统一使用“积分”概念。广告任务、签到、邀请会员返利、会员赠送、游戏奖励都统一表现为积分。

### 选择理由

1. 用户不愿理解余额、积分、会员经验值等多个账户概念。
2. 统一积分能降低理解成本，提高转化效率。
3. 积分既可以承接提现，也可以承接兑换、解锁、消耗、会员权益。
4. 后台仍可区分可提现积分、冻结积分、消耗积分、已提现积分，但不在前台复杂展示。

### 是否可后续调整

可调整。后续如果产品规模扩大，可以在后台继续细分积分类型；前台仍建议保持单一积分表达。

---

## 决策 4：需要上线轻量签到积分功能

### 已确认决策

互动宝需要上线签到积分功能，但只做轻量 MVP，不做复杂成长体系。

### 选择理由

1. 签到是最低成本的每日回访入口。
2. 当前视频下载和影视资源都是按需使用，缺少每日打开理由。
3. 签到可以为后续游戏小程序的任务体系做预演。
4. 签到可与激励广告翻倍、会员加成、连续签到奖励结合。

### 是否可后续调整

可调整。初期只做每日签到、广告翻倍、连续 3/7 天奖励。后续可扩展补签、签到日历、积分倍率、会员专属签到等。

---

## 决策 5：游戏页从“单个小游戏”升级为“互动任务中心”

### 已确认决策

底部 Tab 仍可叫“游戏”，但页面实际定位应升级为“互动任务中心”。

### 选择理由

1. 当前游戏页只有石头剪刀布，内容显得单薄。
2. 用户需要知道“玩游戏为什么有价值”，因此必须突出积分奖励和今日任务。
3. 互动任务中心可以承接签到、小游戏、广告加倍、会员次数、邀请奖励等功能。
4. 该结构也方便后续独立游戏小程序复用。

### 是否可后续调整

可调整。初期可先保留一个小游戏，但页面结构按多个任务和多个游戏入口设计。

---

## 决策 6：影视页作为主要拉新钩子之一

### 已确认决策

影视页继续保留，并作为重要拉新钩子。免费用户通过完成互动或广告复制资源，高清/4K 资源通过邀请好友或会员权益解锁。

### 选择理由

1. 影视资源对泛娱乐用户、大学生群、普通微信群有较强吸引力。
2. 影视资源适合做邀请裂变，例如邀请 3 人解锁高清、邀请 5 人解锁 4K。
3. 影视页可以带动广告观看、会员开通和邀请分享。

### 是否可后续调整

可调整。若影视资源带来高风险或低转化，可降低入口权重；若数据表现好，可强化搜索、追更提醒、订阅片单等功能。

---

## 决策 7：会员权益要从“虚权益”改成“硬权益”

### 已确认决策

会员中心需要重写权益表达，突出可感知的硬权益：更多积分任务、更低提现门槛、更多影视高清权益、更多下载权益、邀请奖励加成。

### 选择理由

1. “专属客服”“定制化功能”等权益不够刺激。
2. 用户开会员前会关注实际能获得什么。
3. 会员应成为积分任务和提现权益的核心杠杆。

### 是否可后续调整

可调整。会员权益可根据实际数据动态调整，包括每日任务次数、积分倍率、提现手续费、邀请返利、影视解锁次数等。

---

## 决策 8：暂缓油价、股票、银行利率、附近加油站等泛工具

### 已确认决策

当前阶段暂不开发油价、股票、银行利率、附近加油站等泛工具功能。

### 选择理由

1. 这些功能与当前积分任务、影视福利、小游戏变现主线关系较弱。
2. 继续堆功能会稀释产品定位。
3. 当前项目最缺的是有效用户、留存、广告收益、会员转化和邀请裂变数据，而不是功能数量。
4. 开发泛工具会增加维护成本和页面复杂度。

### 是否可后续调整

可调整。若后续用户数据证明某类工具能明显提升留存或拉新，可以作为 P2/P3 扩展功能加入“更多工具”。

---

## 决策 9：悦享互动宝作为模型测试场，后续单独规划游戏小程序

### 已确认决策

悦享互动宝当前作为流量入口和商业模型测试场。后续可以单独立项游戏小程序，专门做互动小游戏、积分任务、签到、广告、会员和邀请体系。

### 选择理由

1. 游戏小程序更适合承接高频广告、签到、积分任务、小游戏消耗、会员加速等玩法。
2. 工具小程序如果承载过重游戏赚钱体系，产品定位会混乱。
3. 当前互动宝可以先测试用户是否愿意看广告、做任务、开会员、邀请好友、提现。
4. 游戏小程序可在互动宝验证数据后再深入设计。

### 是否可后续调整

可调整。若互动宝内的游戏/积分数据表现非常好，可以加速拆分独立游戏小程序；若表现一般，则继续把小游戏作为互动宝的辅助模块。

---

## 决策 10：推广先走三类场景，不直接大规模冲羊毛群

### 已确认决策

推广先从大学生社群、普通微信群、影视资源兴趣群、短视频创作者群等开始，小规模测试不同话术。不建议一开始大规模进入羊毛群。

### 选择理由

1. 羊毛群转化快，但更容易造成提现压力和模型失衡。
2. 大学生群、普通微信群、影视兴趣群更适合测试影视资源、积分任务和小游戏入口。
3. 短视频创作者群可用于测试视频下载功能，但不作为主推广方向。

### 是否可后续调整

可调整。等广告收益、提现规则、风控策略稳定后，可以小规模测试羊毛群或兼职副业群，但话术需要隐晦，避免直接表达“看广告赚钱”。
