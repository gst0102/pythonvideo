# 03-mvp-scope.md

## MVP 唯一目标

悦享互动宝当前 MVP 的唯一目标是：

> 验证“工具/影视入口 + 积分任务 + 会员权益 + 邀请裂变”是否能带来有效用户、广告收益、会员转化和次日留存。

MVP 不追求功能丰富度，不追求做成综合工具大全，也不追求马上做完整游戏生态。当前阶段的核心是用最小改造验证以下问题：

1. 用户是否愿意通过视频下载、影视资源或小游戏进入小程序。
2. 用户是否愿意完成签到、小游戏、广告加倍等积分任务。
3. 用户是否理解并接受统一积分体系。
4. 用户是否愿意为了更多积分任务、提现权益、高清资源或邀请奖励开通会员。
5. 用户是否愿意邀请好友来解锁资源或获得积分。
6. 激励广告 eCPM、广告完成率、提现成本、会员收入之间是否能形成可持续模型。

## P0 功能

P0 是当前 MVP 必须优先完成的功能，目标是形成最小商业闭环。

### P0-1：首页积分/签到卡

首页增加“今日福利”或“签到领积分”模块。

建议内容：

- 当前积分展示。
- 今日签到状态。
- 签到得积分。
- 看广告可翻倍。
- 入口按钮：“立即签到”“去做任务”。

目标：让用户第一次进入首页就知道产品不只是视频下载，还可以领取积分、参与互动任务。

### P0-2：轻量签到功能

功能范围：

- 每日签到得积分。
- 看广告翻倍获得更多积分。
- 连续 3 天/7 天签到额外奖励。
- 会员签到积分加成。

暂不做：补签、复杂签到日历、成长等级、复杂勋章体系。

### P0-3：游戏页改为互动任务中心

当前游戏页应从“休闲小游戏”升级为“互动任务中心”。

功能范围：

- 今日可得积分。
- 今日剩余互动次数。
- 当前已获得积分。
- 小游戏入口。
- 签到任务入口。
- 广告加倍入口。
- 会员解锁更多次数提示。

初期小游戏可先保留石头剪刀布，但页面结构要支持未来扩展猜数字、答题、翻牌、2048 等。

### P0-4：统一积分表达

前台统一使用“积分”作为核心概念。

功能范围：

- 广告任务得积分。
- 签到得积分。
- 邀请好友得积分。
- 邀请会员返积分。
- 开通会员赠积分。
- 积分可提现或兑换权益。

建议展示：

- 我的积分。
- 可兑换金额。
- 可提现积分。
- 冻结积分。
- 已提现。

避免同时强调“余额”“积分”“收入”等多个概念，防止用户理解混乱。

### P0-5：会员权益中心重写

会员权益需要从“虚权益”改为“硬权益”。

建议权益：

- 解锁更多每日积分任务。
- 签到积分加成。
- 小游戏互动次数增加。
- 提现门槛降低。
- 提现手续费减免或降低。
- 影视高清/4K 权益。
- 视频下载免广告或更多次数。
- 邀请好友奖励加成。

会员页需要清楚展示普通用户和会员的差异。

### P0-6：邀请好友路径清晰化

功能范围：

- 我的邀请人数。
- 已获得积分。
- 邀请 1 人得什么。
- 邀请 3 人解锁什么。
- 邀请 5 人解锁什么。
- 好友开通会员后返多少积分。
- 一键复制邀请话术。
- 一键生成分享海报或邀请码。

建议利益表达：

- 邀请好友得积分。
- 邀请 3 人解锁高清资源。
- 邀请 5 人解锁 4K 资源。
- 好友开通会员，你获得积分奖励。

### P0-7：新人首日任务路径

第一次进入小程序时，应展示轻量新手任务。

建议任务：

1. 完成签到，获得积分。
2. 玩一局小游戏，获得积分。
3. 观看一次广告翻倍。
4. 邀请好友，解锁更多权益。
5. 查看会员权益。

目标：让用户 60 秒内完成第一个动作，并理解积分、任务、邀请、会员之间的关系。

### P0-8：提现与积分记录基础功能

功能范围：

- 当前积分。
- 可提现积分。
- 冻结积分。
- 已提现记录。
- 提现按钮。
- 提现规则说明。
- 收益明细。

建议规则：

- 新人首提可设置较低门槛，用来建立信任。
- 后续提现门槛、手续费、会员提现权益可动态调整。
- 邀请返利建议设置冻结期，避免异常刷量。

## P1 功能

P1 是 MVP 成立后优先优化的功能。

### P1-1：影视页转化优化

优化内容：

- “订阅”按钮改为“解锁高清”“追更提醒”“加入片单”等更明确文案。
- 免费用户完成互动或观看广告后复制资源。
- 会员每日可直接复制一定次数。
- 积分可兑换免广告复制次数。
- 邀请好友解锁高清/4K 资源。

### P1-2：视频下载失败兜底

功能范围：

- 下载失败提示原因。
- 换链接重试。
- 提交链接反馈。
- 跳转到影视福利或互动任务，减少用户直接流失。

### P1-3：积分兑换权益

可兑换内容：

- 影视高清解锁次数。
- 视频下载免广告次数。
- 提现手续费减免券。
- 会员折扣券。
- 游戏额外次数。

### P1-4：小游戏扩展

新增轻量小游戏：

- 猜数字。
- 每日答题。
- 幸运翻牌。
- 2048 简版。

原则：优先选择开发轻、规则简单、广告承接自然、用户理解成本低的小游戏。

### P1-5：数据看板

需要记录和查看：

- 页面访问。
- 广告展示次数。
- 广告完成率。
- 积分发放。
- 提现申请。
- 会员开通。
- 邀请人数。
- 各入口点击率。

## P2 功能

P2 是后续根据数据选择性扩展的功能。

### P2-1：独立游戏小程序策略验证

若互动宝内游戏任务数据表现好，可开始单独规划游戏小程序。

方向：

- 签到。
- 每日任务。
- 多小游戏。
- 积分消耗。
- 广告加倍。
- 会员加速。
- 邀请裂变。
- 积分兑换/提现。

### P2-2：更多工具入口

仅在主线数据稳定后考虑加入更多工具。

候选：

- 油价查询。
- 股票信息。
- 银行利率。
- 附近加油站。

这些功能暂不作为 MVP 主线。

### P2-3：订阅消息

可用于：

- 签到提醒。
- 影视更新提醒。
- 积分到账提醒。
- 提现状态提醒。
- 会员到期提醒。

## 暂不做清单

当前 MVP 暂不做以下内容：

1. 油价查询。
2. 股票行情。
3. 银行利率。
4. 附近加油站。
5. 复杂积分商城。
6. 复杂会员等级体系。
7. 复杂成长值/经验值体系。
8. 重度棋牌游戏。
9. 斗地主等复杂对战游戏。
10. 独立游戏小程序完整开发。
11. 大规模羊毛群推广。
12. 过度强调“看广告赚钱”的直白文案。
13. 首页堆满所有功能。
14. 年卡高价强推。
15. 过度复杂的二级分销说明。

## 页面/模块范围

### Tab 1：首页

定位：承接入口 + 视频工具 + 今日福利。

模块：

1. 今日福利/签到积分卡。
2. 当前积分展示。
3. 视频下载助手。
4. 热门入口：影视福利、互动任务、邀请好友。
5. 下载失败兜底入口。

### Tab 2：影视

定位：拉新钩子 + 资源权益。

模块：

1. 我的订阅。
2. 番剧片库。
3. 最新电影。
4. 4K 影视。
5. 搜索框。
6. 资源列表。
7. 复制百度/夸克链接。
8. 解锁高清/追更提醒。
9. 邀请好友解锁。

### Tab 3：游戏

定位：互动任务中心。

模块：

1. 今日可得积分。
2. 今日剩余互动次数。
3. 签到入口。
4. 小游戏入口。
5. 广告加倍。
6. 会员更多次数提示。
7. 任务记录。

### Tab 4：我的

定位：积分资产 + 会员 + 邀请 + 提现。

模块：

1. 我的积分。
2. 可兑换金额。
3. 可提现积分。
4. 冻结积分。
5. 提现按钮。
6. 我的收益。
7. 会员中心。
8. 在线客服。
9. 邀请好友。
10. 提现记录。
11. 收益明细。

## 核心用户路径

### 路径 1：新用户首日路径

1. 用户通过微信群、大学生群、影视资源分享或短视频工具入口进入小程序。
2. 首页展示今日福利和签到入口。
3. 用户完成签到，获得积分。
4. 用户进入游戏页玩一局小游戏，获得积分。
5. 用户观看广告翻倍积分。
6. 用户查看影视资源或视频下载功能。
7. 用户被引导邀请好友解锁更多资源或积分。
8. 用户进入我的页查看积分、提现和会员权益。
9. 若对更多任务或提现权益感兴趣，用户开通会员。

### 路径 2：影视资源拉新路径

1. 用户看到影视资源分享。
2. 进入影视页搜索或查看热播资源。
3. 免费用户完成互动或观看广告后复制资源。
4. 用户想解锁高清/4K 资源。
5. 系统提示邀请 3/5 个好友或开通会员。
6. 用户分享小程序给好友。
7. 新用户进入后被引导到签到、游戏、积分任务。

### 路径 3：视频下载工具路径

1. 用户进入首页，粘贴视频分享链接。
2. 点击开始解析。
3. 免费用户观看激励广告后下载。
4. 会员用户可直接下载或享受更多下载次数。
5. 若解析失败，提示换链接、提交反馈或进入其他福利任务。
6. 用户被引导查看积分任务或会员中心。

### 路径 4：会员转化路径

1. 用户完成若干积分任务。
2. 用户看到普通用户每日任务次数有限。
3. 系统提示会员可解锁更多积分任务、更低提现门槛、更多影视权益、邀请奖励加成。
4. 用户进入会员中心。
5. 用户选择月卡/季卡/年卡。
6. 开通后获得会员权益和赠送积分。

## MVP 验证指标

### 用户指标

1. 新增用户数。
2. 日活用户数 DAU。
3. 次日留存率。
4. 首次进入后 60 秒内完成动作比例。
5. 签到完成率。
6. 游戏参与率。
7. 影视页访问率。
8. 视频下载成功率。

### 广告指标

1. 激励广告展示次数。
2. 激励广告完成率。
3. eCPM。
4. 单用户每日广告观看次数。
5. 广告观看后继续使用比例。

### 积分/提现指标

1. 人均发放积分。
2. 可提现积分总额。
3. 提现申请人数。
4. 提现总金额。
5. 首提完成率。
6. 提现后次日回访率。

### 会员指标

1. 会员页访问率。
2. 会员购买转化率。
3. 月卡/季卡/年卡购买比例。
4. 会员用户每日任务完成次数。
5. 会员用户广告观看次数。
6. 会员用户邀请人数。

### 邀请指标

1. 邀请按钮点击率。
2. 分享成功率。
3. 邀请注册人数。
4. 邀请 3 人/5 人达成率。
5. 邀请会员付费人数。

### 商业指标

1. 单日广告收入。
2. 单日会员收入。
3. 单日提现成本。
4. 广告收入与积分发放成本比例。
5. 单用户收入 ARPU。
6. 会员用户收入贡献。
7. 投放/推广带来的回本周期。
