# LinuxDo 采集与混合分类同步开发文档

## 功能目标

把 LinuxDo 云资产资源接入悦享新版网盘资源库，并与金山文档影视资源形成互补供给：

- LinuxDo 每日采集资源候选。
- 规则库优先分类，DeepSeek 只在低置信时兜底。
- 影视资源跨来源去重，KDocs 优先，LinuxDo 补充缺失网盘。
- 影视剧按完整度定价：完结/全集/合集 20 分，更新中或普通影视资源 5 分。
- 小程序资源卡展示上架时间。

## 业务规则

- 一级分类：影视剧、自媒体素材、编程课程、AI工具、电商运营、学习办公、养生健康、软件工具、本地生活、其他资源。
- 二级分类暂不落库，用 tags 表达。
- LinuxDo 资源只在高置信、非重复、链接明确时自动入库。
- 同片名同网盘或同链接默认跳过。
- 同片名但新增网盘链接允许作为补充资源入库。
- DeepSeek 第一阶段只做分类和标签，不做客服、投诉审核或最终裁定。

## 采集规则

| 来源 | 频率 | 每次数量 | 入库策略 | 备注 |
|---|---:|---:|---|---|
| KDocs 影视剧/番剧 | 每 1 小时 | 最新日期分组最多 20 条 | 直接同步到新版网盘资源 | 不足 20 条不补旧数据 |
| KDocs 电影 | 每天 00:00 | 最新日期分组最多 20 条 | 直接同步到新版网盘资源 | 与 4K 同一任务 |
| KDocs 4K影视 | 每天 00:00 | 最新日期分组最多 20 条 | 直接同步到新版网盘资源 | 与电影同一任务 |
| LinuxDo 云资产 | 每 12 小时 | 前 20 条 | 高置信自动入库，低置信进待审核 | 与 KDocs 做影视去重 |

## LinuxDo 历史回补

- 支持从 `2026-01-01` 回补到当前日期。
- 历史回补使用独立命令，不放进日常定时任务，避免服务器压力过大。
- 建议先在本地或低峰期运行，并观察自动入库、跳过重复、进入待审核的数量。

## KDocs 最新资源过滤

- 如果文档内有日期分组，例如 `2026.06.13`、`06月13日`，只同步最新日期分组下的资源。
- 日期分组也支持 `2026-06-13 更新`、`6月13日新增`、`今日更新`、`昨天新增` 这类写法。
- 资源标题里单独出现日期但没有“更新/新增/日期/分割”等提示词，不会被当成日期分组。
- 最新分组不足 20 条时，只同步实际数量，不从旧日期补满。
- 如果文档没有日期分组，才退回为取解析结果前 20 条。

示例：

```bash
python scripts/linuxdo_netdisk_sync.py backfill --browser-fallback
```

如果要手动控制扫描页数：

```bash
python scripts/linuxdo_netdisk_sync.py backfill --pages 120 --limit 0 --since-date 2026-01-01
```

## 浏览器资源保护

- KDocs 和 LinuxDo 都必须使用统一浏览器守护。
- 同一时间默认只允许 1 个浏览器采集任务。
- 每次采集结束必须关闭页面、上下文和浏览器。
- 守护层会在异常退出后清理新产生的残留浏览器进程，避免服务器浏览器堆积。

## 数据结构

`netdisk_resources` 增加：

- `tags`
- `source_type`
- `source_ref`
- `normalized_title`

接口返回增加：

- `created_at`
- `published_at`
- `tags`
- `source_type`
- `source_ref`

## 验收条件

- 重复 LinuxDo 采集不会重复入库。
- LinuxDo 与 KDocs 相同影视链接会跳过。
- LinuxDo 与 KDocs 同片名但不同网盘可以补充入库。
- 影视更新中资源 5 分，完结/全集/合集资源 20 分。
- 资源列表、首页、收藏、详情能展示上架时间。
- DeepSeek 不可用时不影响规则分类和已有 KDocs 同步。
