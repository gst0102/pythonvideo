# 02-task-breakdown.md

## 1. 任务说明

本文档用于指导 Codex 或开发人员按阶段二文档执行悦享互动宝 MVP v0.1 改造。

任务原则：

1. 只做 MVP 范围内功能。
2. 优先完成用户路径闭环，而不是继续堆功能。
3. 所有规则必须配置化，避免写死。
4. 涉及积分、广告回调、提现的地方必须保证幂等和账务记录。
5. mock 与真实接入边界必须清楚。

## 2. 开发阶段划分

### Phase 0：项目识别与现状检查

目标：让 Codex 先理解当前代码结构，不要盲目重构。

任务：

1. 扫描项目目录结构。
2. 识别微信小程序前端目录。
3. 识别后端服务目录。
4. 识别当前已有页面：首页、影视、游戏、我的。
5. 识别当前已有接口：登录、用户信息、积分/余额、广告、会员、提现、邀请、影视资源、视频解析。
6. 输出当前代码结构备注。

交付：

- 不修改业务逻辑。
- 在开发日志中记录当前入口文件、页面文件、接口文件、数据模型文件。

### Phase 0.5：静默登录与开发方式确认

目标：在原项目内补齐或确认微信静默登录，不另起独立项目重写。

任务：

1. 在当前仓库中识别现有微信登录流程。
2. 如已有 `wx.login + code2Session + token`，优先复用并补齐缺失字段。
3. 如未完整实现，新增静默登录接口。
4. 登录成功后自动创建或更新用户记录。
5. 首次创建用户时同步初始化积分账户、邀请码和新人任务状态。
6. 如果启动参数存在 `invite_code`，在静默登录时传给后端并绑定邀请关系。
7. MVP 阶段不强制获取头像、昵称、手机号。
8. 默认昵称使用“悦享用户xxxx”，默认头像使用系统默认头像。
9. 所有积分、签到、任务、会员、邀请、提现接口都必须从 token 解析 user_id，不能信任前端传入的 user_id。

验收：

- 新用户首次打开小程序无需授权头像昵称即可进入。
- 新用户可直接签到、玩小游戏、完成互动任务、查看影视资源。
- 邀请链接进入的新用户能在登录后绑定上级。
- 用户、积分账户、邀请码能自动初始化。
- AppSecret 和 session_key 不出现在前端代码。


### Phase 1：首页与新人承接

目标：让新用户进入后立即看到“今日福利/积分/签到/任务入口”。

任务：

1. 首页顶部增加“今日福利卡”。
2. 展示当前积分、今日签到状态、今日可领提示。
3. 增加“立即签到”按钮。
4. 增加“去做任务”按钮，跳转游戏 Tab。
5. 保留视频下载助手。
6. 在视频下载模块下增加热门入口：影视福利、互动任务、邀请好友。
7. 视频解析失败时增加兜底文案和跳转入口。

页面状态：

1. 未登录/未授权。
2. 已登录未签到。
3. 已登录已签到。
4. 解析中。
5. 解析成功。
6. 解析失败。

验收：

- 用户进入首页首屏能看到积分/签到入口。
- 不影响原有视频解析流程。
- 解析失败时不只显示错误，需要有下一步入口。

### Phase 2：签到积分

目标：上线简单签到能力，形成每日回访入口。

任务：

1. 新增签到接口。
2. 新增查询今日签到状态接口。
3. 新增签到记录表。
4. 新增积分明细记录。
5. 支持连续签到天数计算。
6. 支持会员签到加成。
7. 支持看广告后签到积分加倍。
8. 防止重复签到。
9. 防止重复广告回调发积分。

默认规则：

- 普通用户每日签到：1 积分。
- 会员每日签到：2 积分。
- 看广告翻倍：额外 1–3 积分，后台可配置。
- 连续 3 天：额外 3 积分。
- 连续 7 天：额外 10 积分。

验收：

- 同一用户同一天只能签到一次。
- 广告翻倍只能对当天签到生效一次。
- 每次积分变化必须产生积分明细。

### Phase 3：游戏页改为互动任务中心

目标：把游戏页从单个小游戏升级为积分任务承接页面。

任务：

1. 页面标题从“休闲小游戏”调整为“互动任务”或“小游戏福利”。
2. 顶部增加今日积分统计。
3. 展示今日已得积分、今日剩余任务次数。
4. 展示签到任务入口。
5. 展示小游戏入口卡片。
6. 保留石头剪刀布游戏。
7. 游戏完成后发放积分。
8. 支持看广告领取/加倍积分。
9. 会员展示更多任务次数提示。
10. 预留后续游戏列表结构。
11. 非会员需要看到会员任务入口和会员每日任务次数差异，但只能完成普通用户 10 次任务。
12. 会员用户根据会员等级展示 100/150/200 次任务上限。

默认规则：

- 普通用户每日游戏积分任务次数：10 次。
- 会员每日游戏积分任务次数：100 次。
- 每局基础积分：1–2 积分，后台可配置。
- 广告加倍后积分：基础积分的 2 倍或配置值。

验收：

- 游戏页首屏能看懂“玩游戏得积分”。
- 游戏完成后积分到账。
- 任务次数耗尽后提示开通会员或明日再来。
- 会员用户显示更高次数。

### Phase 4：我的页统一积分表达

目标：降低用户理解成本，前台统一用“积分”作为主概念。

任务：

1. 将“当前余额/当前积分/累计收入”等展示整理为统一积分资产卡。
2. 展示我的积分、可兑换金额、可提现积分、冻结积分、已提现。
3. 保留立即提现按钮。
4. 会员权益卡文案重写。
5. 邀请好友卡文案重写。
6. 我的收益页展示积分明细和提现记录。

推荐展示：

- 我的积分：xxx。
- 可兑换金额：x.xx 元。
- 可提现积分：xxx。
- 冻结积分：xxx。
- 已提现：x.xx 元。

验收：

- 前台不再同时强化“余额”和“积分”两个主概念。
- 用户能理解积分与可兑换金额关系。
- 每个资产字段数据来自后端，不写死。

### Phase 5：会员中心优化

目标：让会员权益更具体、能转化。

任务：

1. 会员页展示月卡、季卡、年卡。
2. 展示价格：19.9、49.9、99.9。
3. 展示会员权益对比。
4. 会员权益卡在我的页展示核心权益。
5. 支持会员状态判断。
6. 支持会员过期时间展示。
7. 支持开通会员赠积分。
8. 支持会员每日任务次数、签到加成、提现门槛等配置。

会员文案：

> 开通后解锁更多积分任务、影视高清权益、邀请奖励和提现权益。

验收：

- 用户能清楚知道会员多了什么。
- 会员状态在首页、游戏页、影视页、我的页均可判断。
- 会员购买成功后权益立即生效。

### Phase 6：邀请好友

目标：让邀请从入口变成任务目标。

任务：

1. 邀请页展示邀请码/邀请链接。
2. 展示我的邀请人数。
3. 展示邀请获得积分。
4. 展示邀请 3 人/5 人权益进度。
5. 展示好友开通会员返积分规则。
6. 支持一级邀请关系绑定。
7. 支持二级邀请关系记录。
8. 支持会员返利积分冻结。
9. 增加一键复制邀请话术。
10. 可选：生成邀请海报。

默认规则：

- 邀请注册奖励积分：后台配置，默认 10 积分。
- 邀请 3 人解锁高清资源。
- 邀请 5 人解锁 4K 资源。
- 一级会员返利 50% 等值积分。
- 二级会员返利 5% 等值积分。
- 邀请返利冻结期 7 天。

验收：

- 新用户通过邀请进入后能绑定上级。
- 邀请记录可查。
- 会员返利进入冻结积分。
- 邀请页面能让用户知道“还差几人解锁”。

### Phase 7：影视页权益化

目标：把影视页从资源列表改成资源权益入口。

任务：

1. 将“订阅”按钮文案改为“解锁高清”“加入片单”或“追更提醒”。
2. 免费用户复制资源前完成互动或广告。
3. 会员用户每日可直接复制一定次数。
4. 支持积分免广告复制资源。
5. 支持邀请解锁高清/4K。
6. 资源列表加载失败时显示兜底提示。
7. 搜索无结果时显示推荐路径。

验收：

- 免费用户复制资源前有互动流程。
- 会员权益在影视页生效。
- 邀请权益在影视页可感知。
- 不影响现有资源列表和搜索功能。

### Phase 8：提现与收益记录

目标：建立最小可用提现闭环。

任务：

1. 提现申请入口。
2. 提现记录列表。
3. 积分明细列表。
4. 提现状态：待审核、已通过、已驳回、已打款。
5. 提现门槛判断。
6. 提现手续费配置。
7. 会员提现权益判断。
8. 后台审核状态字段预留。

默认规则：

- 100 积分 = 1 元。
- 新人首提 1 元。
- 普通用户后续 5 元起提。
- 会员 1 元起提。
- 提现默认人工审核。

验收：

- 不满足提现门槛时不能提交。
- 提现提交后扣减或冻结对应可提现积分。
- 提现状态变化有记录。
- 提现失败可以退回积分。

### Phase 9：数据埋点与运营统计

目标：MVP 上线后能判断是否值得继续。

任务：

1. 新增事件埋点。
2. 记录用户首次进入来源。
3. 记录 Tab 点击。
4. 记录签到完成。
5. 记录游戏开始/完成。
6. 记录广告展示/完成/失败。
7. 记录影视复制。
8. 记录会员页访问和购买。
9. 记录邀请点击、分享、注册。
10. 记录提现申请。

核心指标：

1. 新增用户数。
2. DAU。
3. 次日留存。
4. 首次 60 秒完成动作比例。
5. 签到完成率。
6. 游戏参与率。
7. 广告完成率。
8. 会员转化率。
9. 邀请注册人数。
10. 提现成本。

验收：

- 每个关键事件有日志或埋点记录。
- 后台能按日期统计核心指标。

## 3. 任务优先级总览

### P0 必须完成

1. 首页今日福利/签到卡。
2. 签到积分。
3. 游戏页改互动任务中心。
4. 我的页统一积分展示。
5. 会员权益文案和状态判断。
6. 邀请基础链路。
7. 积分明细。
8. 提现申请与记录。
9. 核心埋点。

### P1 建议完成

1. 连续签到奖励。
2. 广告翻倍。
3. 影视积分免广告复制。
4. 邀请 3/5 人权益进度。
5. 会员每日影视直接复制次数。
6. 新人任务弹窗。

### P2 后续完成

1. 邀请海报。
2. 猜数字、答题、幸运翻牌等新游戏。
3. 积分商城。
4. 会员限时活动。
5. 独立游戏小程序策略落地。

## 4. 不做范围

1. 不做油价、股票、银行利率、加油站。
2. 不做复杂成长等级。
3. 不做重型游戏。
4. 不做自动大额提现。
5. 不做承诺收益的页面文案。
6. 不做完整后台管理系统，除非当前项目已有后台基础。
7. 不重构全部旧代码，只做 MVP 所需最小改造。
