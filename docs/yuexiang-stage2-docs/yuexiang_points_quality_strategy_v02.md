# 悦享资源库积分经济系统与资源质量策略文档

> 版本：MVP v0.2  
> 产品名称：悦享资源库  
> 核心定位：赚积分，换资源，找不到就悬赏  
> 核心逻辑：资源是诱饵，积分是系统，邀请是增长，上传是供给，补链是质量，充值是变现。  

---

## 1. 项目核心判断

悦享资源库表面是资源库，本质是一个积分经济系统。

用户为了获取资源，需要积分；  
用户为了获得积分，需要完成平台希望发生的行为；  
平台通过积分引导用户产生增长、内容、活跃、资源维护和付费。

核心闭环：

```text
用户注册送100分
↓
用户获取资源，积分减少
↓
积分不足
↓
用户选择：
1. 签到/小游戏慢慢赚
2. 上传资源赚
3. 完成求资源赚
4. 邀请好友赚
5. 补链维护赚
6. 充值买积分
↓
用户再次获取资源或发布悬赏
↓
平台获得活跃、内容、拉新、资源质量和收入
```

## 2. 积分系统的核心原则

积分不是简单奖励，而是平台内部的流通货币。

积分系统需要同时满足：

```text
用户能赚到
用户会不够用
用户愿意拉人赚
用户愿意上传资源赚
用户愿意维护资源赚
用户愿意充值补
平台不会无限通胀
```

### 2.1 免费积分只能满足轻度使用

签到、小游戏等每日免费任务不能给太多积分。

建议每日基础免费积分控制在 7 - 9 分左右，刚好够用户每天获取 1 个普通资源。

这样可以维持活跃，但不会让用户完全没有充值、邀请和上传动力。

### 2.2 高价值积分来自高价值行为

高价值行为包括：

```text
邀请真实用户
上传有效资源
完成求资源悬赏
补充失效链接
好友首次充值
资源长期有效
资源被持续下载和收藏
```

这些行为对平台增长、内容供给、资源质量和收入有直接价值，因此可以给予更高积分。

### 2.3 积分消耗要略快于积分产生

如果积分产生太快，用户不缺积分，就不会邀请和充值。

如果积分产生太慢，用户会觉得平台太抠，不愿意参与。

MVP 阶段建议观察：

```text
每日积分产出量
每日积分消耗量
用户平均积分余额
充值转化率
邀请转化率
上传转化率
补链完成率
```

再动态调整积分奖励。

### 2.4 奖励要看结果，不只看动作

不要只要用户做了动作就高额奖励，要看动作是否产生真实价值。

例如：

```text
邀请不能只看注册，要看好友是否首次获取资源
上传不能只看提交，要看是否审核通过和持续有效
补链不能只看提交，要看是否验证有效
求资源不能只看提交，要看是否被采纳
资源排名不能只看上传者积分，要看资源质量
```

## 3. 三套数值体系：积分、信用分、贡献值

为了避免“积分越多排名越靠前”的不公平问题，建议将用户数值拆成三套体系。

### 3.1 积分

积分是可消费货币。

用于：

```text
获取资源
发布求资源悬赏
求资源加急
求资源置顶
解锁官方合集
充值购买
```

积分不应该直接决定资源排名。

### 3.2 信用分

信用分是用户可靠程度。

用于：

```text
判断用户是否可靠
是否免审核
是否限制上传
是否降低曝光
是否进入人工审核
```

信用分受这些行为影响：

```text
上传有效资源
资源长期有效
补链及时
资源被确认失效
资源被确认违规
恶意投诉
短期大量失效
```

### 3.3 贡献值

贡献值是用户对平台的贡献程度。

用于：

```text
资源排序加权
贡献榜排名
上传者等级
优质资源曝光
官方推荐候选
```

贡献值来源：

```text
上传资源审核通过：+5
资源被下载：+1
资源被收藏：+1
资源被好评：+2
求资源被采纳：+10
补链成功：+5
资源有效满7天：+5
资源有效满30天：+20
```

## 4. 新用户积分

### 4.1 新用户初始积分

```text
新用户注册成功：+100分
```

目的：

```text
降低首次使用门槛
让用户可以立即体验获取资源
让用户理解积分的价值
```

### 4.2 新用户限制

为了防止多账号薅初始积分，建议设置：

```text
新用户前24小时最多获取5个资源
新用户初始积分不可转赠
异常账号限制下载和上传
同设备多账号进入风控观察
```

---

## 5. 每日活跃积分

每日活跃积分用于提高留存，但不应该成为主要积分来源。

### 5.1 每日签到

```text
每日签到：随机 +1 到 +3分
连续3天签到：额外 +3分
连续7天签到：额外 +8分
中断后连续签到天数重置
```

### 5.2 小游戏 / 激励广告

```text
小游戏并观看激励广告：+2分/次
每天最多3次
每日最高获得6分
```

### 5.3 每日基础免费积分上限

普通用户每天通过签到和小游戏可获得：

```text
签到：1 - 3分
小游戏广告：6分
合计：7 - 9分
```

这个额度刚好能获取 1 个普通资源，但不够大量获取精选资源。

---

## 6. 邀请积分

邀请是增长核心，必须放在首页和赚积分页的高优先级位置。

### 6.1 邀请奖励规则

建议采用阶梯奖励：

```text
邀请好友注册：+5分
好友首次获取资源：再 +10分
好友首次充值成功：再 +20分
```

一个有效邀请最高奖励：

```text
普通有效用户：15分
充值用户：35分
```

### 6.2 邀请奖励限制

```text
每日邀请奖励上限：50分
每个新用户只奖励一次
同设备 / 同微信环境异常账号不发放奖励
好友注册后24小时内完成首次获取资源，才发放二段奖励
好友首次充值成功后，才发放充值邀请奖励
```

### 6.3 邀请奖励逻辑

不建议邀请注册直接给高分，因为容易被小号刷积分。

更合理的方式是：

```text
注册给小奖励
首次使用给中奖励
首次充值给大奖励
```

这样可以鼓励用户拉来真实用户，而不是空账号。

---

## 7. 上传资源积分

上传资源是内容供给核心，应该设计成一次奖励 + 长期收益。

### 7.1 上传奖励建议改为分期发放

为了防止用户上传短期链接、拿完积分就跑，不建议审核通过后一次性发完 5 分。

建议改成：

```text
审核通过：先发 +2分
资源有效满7天：再发 +3分
```

对用户展示文案：

```text
上传有效资源最高得5分
审核通过先得2分，链接有效满7天再得3分
```

这样既保留上传动力，也能防止两天失效链接卡 bug。

### 7.2 下载分成奖励

普通资源：

```text
下载者扣5分
上传者得1分
平台回收4分
```

精选资源：

```text
下载者扣10分
上传者得2分
平台回收8分
```

官方合集：

```text
下载者扣20分
平台获得全部积分
用户投稿被官方收录时，可一次性奖励20分
```

### 7.3 下载奖励限制

```text
同一用户下载同一资源，只奖励上传者一次
单个资源每日下载奖励上限：10分
新用户异常下载不立即计入热门升级
异常互刷进入风控观察
```

### 7.4 资源里程碑奖励

```text
资源累计10次下载：额外 +5分
资源累计30次下载：额外 +10分
资源7天无失效投诉：额外 +5分
资源30天持续有效：额外 +20贡献值
```

## 8. 求资源悬赏积分

求资源是平台最有生命力的功能之一。它可以解决两个问题：

```text
用户找不到资源
平台不知道用户真正想要什么
```

### 8.1 发布求资源

```text
发布求资源：冻结5 - 50分
超时无人采纳：积分退回
采纳资源后：积分发放给提交者
```

### 8.2 悬赏档位建议

发布求资源时，建议提供三个推荐档位：

```text
普通悬赏：10分
加急悬赏：20分
高赏悬赏：50分
```

对应展示效果：

```text
10分：普通展示
20分：靠前展示
50分：高亮展示
```

### 8.3 提交资源奖励

```text
提交资源被采纳：获得悬赏积分
采纳后的资源可同步进入资源库
后续其他用户下载该资源，提交者继续获得下载分成
```

## 9. 补链积分与失效处罚

补链是资源库质量维护的关键。

### 9.1 失效投诉流程

不要一个人投诉就扣分。

建议流程：

```text
1人投诉：资源标记为疑似失效
2个不同用户投诉：资源暂时隐藏
系统通知上传者补链
上传者在规定时间内补链
补链成功：恢复展示
超时未补链：扣积分、扣信用、降低曝光
```

### 9.2 上传者补链期限

```text
普通资源：24小时内补链
精选资源：24小时内补链
官方合集：48小时内补链
```

### 9.3 原上传者补链成功

```text
24小时内补链成功：
不扣积分
不扣信用
额外 +2分
资源恢复展示
最近验证时间更新
```

### 9.4 他人补链成功

```text
他人补链成功：
补链者 +5分
资源恢复展示
原上传者后续分成降低50%或取消
如果原上传者长期不维护，收益转给补链者
```

### 9.5 补链奖励

```text
补充普通资源链接成功：+5分
补充精选资源链接成功：+8分
补充官方合集链接成功：+10分
每日补链奖励上限：30分
```

### 9.6 补链验证

补链不能用户说成功就立即发分。

建议流程：

```text
用户提交补链
↓
进入待验证状态
↓
管理员审核或2个用户确认有效
↓
发放补链积分
↓
资源恢复展示
```

MVP 阶段可以先由管理员审核，后续再考虑用户共同验证或自动检测。

## 10. 资源有效期与失效扣分

为了防止用户上传短期链接卡 bug，需要设置最低有效期要求。

### 10.1 最低有效期要求

```text
普通资源：至少有效7天
精选资源：至少有效15天
官方合集：至少有效30天
```

### 10.2 7天内失效

资源上线后 7 天内确认失效，且上传者未及时补链：

```text
追回上传奖励 5分
额外扣 5分
信用分 -3
资源下架或隐藏
```

如果上传奖励采用分期发放，则处理为：

```text
不发放7天有效奖励 +3分
额外扣 5分
信用分 -3
资源下架或隐藏
```

### 10.3 7 - 30天内失效

确认失效且未补链：

```text
扣 5分
信用分 -2
资源隐藏
```

### 10.4 30天后自然失效

资源已经服务过一段时间，惩罚可以轻一点。

确认失效且未补链：

```text
扣 0 - 2分
信用分 -1
资源隐藏
```

### 10.5 负积分机制

如果用户积分余额不足以扣罚，允许积分变成负数。

```text
积分余额不足时，记为负积分
后续用户获得积分时，先抵扣负积分
负积分用户限制获取资源、上传资源和发布悬赏
```

这样可以防止用户拿完积分花掉后，通过失效资源逃避惩罚。

## 11. 防短链卡 bug 规则

为了防止用户上传两天就失效的短期链接，需要设置强约束。

### 11.1 短期失效惩罚

```text
资源审核通过后7天内失效，追回上传奖励
7天内失效超过3次，暂停上传权限
短期失效率过高，上传资源默认人工审核
资源有效期越长，排名越高
资源30天有效，可获得长期有效奖励
```

### 11.2 用户短期失效率风控

建议规则：

```text
近30天上传资源数 ≥ 5
且7天内失效率 > 30%
```

触发后：

```text
信用分 -10
上传资源全部进入人工审核
暂停上传奖励
上传奖励改为7天后发放
限制每日上传数量
```

### 11.3 上传奖励延迟发放

对风险用户建议：

```text
普通用户：审核通过先发2分，7天有效再发3分
风险用户：7天有效后一次性发5分
高风险用户：暂停上传奖励，只保留下载分成
```

## 12. 充值积分

充值是变现核心，但第一版不要设计太复杂。

### 12.1 MVP 充值档位

第一版建议只保留一档：

```text
10元 = 100积分
```

好处：

```text
用户理解简单
对应普通资源5分/个，相当于10元可获取20个普通资源
方便测试用户是否愿意付费
```

### 12.2 后续可增加档位

当基础转化跑通后，可以增加：

```text
3元 = 30积分
10元 = 100积分
19.9元 = 220积分
29.9元 = 360积分
9.9元月卡：每天领取15积分
```

如果 10 元转化偏弱，可以先增加 3 元低价包，用于刺激冲动购买。

## 13. 积分消耗入口

积分必须有足够多的消耗场景，否则会通胀。

### 13.1 资源消耗

```text
普通资源：-5分
精选资源：-10分
官方合集：-20分
```

### 13.2 求资源消耗

```text
发布求资源：冻结5 - 50分
求资源置顶：-10分
求资源加急：-20分
高赏悬赏：最高50分
```

### 13.3 内容合集消耗

后续可以扩展：

```text
美食/探店合集：-5 到 -10分
热门榜单解锁：-5分
高级筛选次数：超出免费次数后扣分
官方整理包：-20分
```

### 13.4 权益消耗

后续可以扩展：

```text
资源卡片置顶
上传资源曝光加成
求资源优先展示
查看热门榜单
兑换会员权益
```

## 14. 资源排名规则

### 14.1 积分高是否应该排名靠前

不建议直接用用户积分余额决定资源排名。

因为积分是可消费货币，用户可能通过充值、邀请等方式获得积分，但这不代表他上传的资源质量高。

更合理的做法：

```text
积分余额不直接决定排名
信用分和贡献值影响排名
资源本身数据决定主要排名
长期有效资源优先展示
```

### 14.2 排名核心因素

资源排名应该综合：

```text
下载次数
收藏次数
好评率
投诉率
失效次数
最近验证时间
是否精选
是否官方整理
是否长期有效
上传者信用分
上传者贡献值
补链响应速度
```

### 14.3 简化排名公式

MVP 阶段可先采用简单公式：

```text
基础分 = 下载数 × 1 + 收藏数 × 2 + 好评数 × 3
扣分 = 投诉数 × 10 + 失效次数 × 20
加成 = 上传者信用分 / 10 + 长期有效奖励 + 精选/官方加成
最终分 = 基础分 - 扣分 + 加成
```

### 14.4 推荐排序逻辑

首页推荐、分类页排序和搜索结果可以采用：

```text
官方精选优先
长期有效优先
最近验证优先
高收藏高下载优先
低投诉低失效优先
高信用上传者适度加权
```

### 14.5 不建议的排序逻辑

不要采用：

```text
用户积分越高，资源越靠前
充值越多，资源越靠前
上传越多，不看质量就靠前
新资源无验证就强推
```

## 15. 赚积分页设计策略

赚积分页不是普通任务页，而是：

```text
增长中心
变现入口
资源供给入口
活跃任务中心
```

### 15.1 页面模块顺序

建议顺序：

```text
顶部：
当前积分
今日已赚 / 今日可赚
充值积分
邀请好友

高收益任务：
邀请好友使用
上传有效资源
完成求资源
补充失效链接

每日任务：
每日签到
小游戏赚积分

充值入口：
10元=100积分
```

### 15.2 高收益任务

```text
邀请好友使用：最高+35分
上传有效资源：最高+5分，被下载持续得分
完成求资源：获得悬赏积分
补充失效链接：+5分起
```

### 15.3 每日任务

```text
每日签到：+1 到 +3分
小游戏赚积分：+2分/次，每天3次
```

### 15.4 页面重点

邀请和充值必须放在顶部。

签到和小游戏只是活跃任务，不是核心增长入口。

## 19. 风控规则

积分经济系统一定要防刷。

### 19.1 邀请防刷

```text
同设备多账号异常检测
同微信环境异常检测
好友未完成首次资源获取，不发放二段奖励
好友未完成充值，不发放充值邀请奖励
每日邀请奖励上限50分
```

### 19.2 上传防刷

```text
新用户每日上传数量限制
上传资源需审核通过才奖励
重复资源不奖励
违规资源扣分或封禁
上传奖励分期发放
高风险用户上传奖励延迟发放
```

### 19.3 下载防刷

```text
同一用户下载同一资源只奖励上传者一次
同设备多个账号互相下载进入观察
单个资源每日下载奖励上限10分
新用户异常下载不计入热门排序
```

### 19.4 补链防刷

```text
补链需审核或用户确认
无效补链不奖励
恶意补链扣信用分
每日补链奖励上限30分
```

### 19.5 失效防刷

```text
7天内失效追回上传奖励
多次短期失效扣信用分
短期失效率过高暂停上传权限
积分不足可记负积分
长期失效未处理降低资源曝光
```

## 22. 调整策略

### 22.1 免费积分太多

表现：

```text
用户积分余额普遍很高
资源获取多但充值少
邀请动力弱
```

调整：

```text
降低每日任务奖励
提高精选资源积分消耗
增加求资源加急和置顶消耗
限制广告积分次数
```

### 22.2 用户参与太少

表现：

```text
签到少
上传少
邀请少
资源获取少
```

调整：

```text
提高邀请奖励
提高上传审核通过奖励
增加新手任务
首页强化积分卡
增加热门资源吸引
```

### 22.3 充值转化弱

表现：

```text
积分不足用户多
但充值点击少
```

调整：

```text
增加3元低价积分包
优化积分不足弹窗
增加官方精选资源
增加限时资源合集
强化充值10元=100分的价值感
```

### 22.4 资源失效率高

表现：

```text
资源上线后很快失效
用户投诉多
补链响应慢
下载后满意度低
```

调整：

```text
上传奖励改为延迟发放
提高7天内失效惩罚
短期失效率高的用户进入人工审核
增加补链奖励
降低失效用户资源排名
```

## 23. 最终总结

悦享资源库不是单纯的资源库，而是积分驱动的互助系统。

最终逻辑：

```text
资源是诱饵
积分是系统
邀请是增长
上传是供给
求资源是需求
补链是质量
信用是风控
贡献是排序
充值是变现
```

第一版最重要的是跑通：

```text
赚积分
花积分
积分不足
邀请赚积分
充值买积分
上传赚积分
悬赏流通积分
补链维护质量
失效形成惩罚
贡献决定排名
```

只要这套闭环跑通，产品就不只是一个资料库，而是一个可持续增长的积分经济平台。
