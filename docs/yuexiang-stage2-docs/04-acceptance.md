# 04-acceptance.md

## 1. 验收目标

本阶段验收目标：

> 悦享互动宝完成 MVP v0.1 改造后，用户可以围绕“签到得积分、玩游戏得积分、影视权益、视频下载、会员、邀请、提现”形成最小闭环。

验收时不要求完成所有后续扩展功能，但必须保证 P0 功能可用、数据正确、关键路径无阻断。

## 2. 总体验收标准

1. 小程序能正常启动。
2. 四个 Tab 均可进入：首页、影视、游戏、我的。
3. 首页首屏能看到积分/签到/今日福利入口。
4. 用户能完成签到并获得积分。
5. 用户能玩石头剪刀布并获得积分。
6. 用户能看到自己的积分、可兑换金额、可提现积分、冻结积分。
7. 用户能进入会员中心，看到会员价格和权益。
8. 用户能进入邀请好友页，看到邀请码、邀请进度、邀请奖励说明。
9. 用户能提交提现申请。
10. 用户能使用原有视频解析功能，失败时有兜底入口。
11. 用户能浏览影视资源，复制资源前有权益/互动判断。
12. 所有积分变动都有明细记录。
13. 关键事件有埋点或日志。

## 3. 首页验收

### 3.1 页面内容

必须显示：

1. 今日福利/签到卡。
2. 当前积分或积分入口。
3. 立即签到按钮或签到状态。
4. 视频下载助手。
5. 粘贴输入框。
6. 开始解析按钮。
7. 影视福利、互动任务、邀请好友入口。

### 3.2 交互验收

1. 未签到用户点击签到后，积分增加。
2. 已签到用户再次点击，提示今日已签到。
3. 点击“去做任务”跳转游戏 Tab。
4. 点击“影视福利”跳转影视 Tab。
5. 点击“邀请好友”跳转邀请页或我的页邀请模块。
6. 粘贴链接后点击解析，走原有解析流程。
7. 解析失败时展示重试、反馈、去任务、去影视等兜底入口。

### 3.3 不通过情况

1. 首页仍然只有视频下载，没有积分/签到入口。
2. 签到按钮点击无反馈。
3. 解析失败只显示错误，没有下一步路径。

## 4. 签到验收

### 4.1 功能验收

1. 用户每日可以签到一次。
2. 签到成功后发放积分。
3. 签到成功后生成积分明细。
4. 同一天重复签到不会重复发积分。
5. 会员签到积分高于普通用户或可配置。
6. 连续签到天数能正确计算。
7. 广告翻倍成功后额外发积分。
8. 同一天广告翻倍不能重复发放。

### 4.2 数据验收

检查：

1. checkin_records 有签到记录。
2. point_details 有签到积分明细。
3. user_points 汇总值正确。
4. 重复请求不会重复增加积分。

## 5. 游戏/互动任务验收

### 5.1 页面验收

必须显示：

1. 页面标题：互动任务/小游戏福利/休闲互动之一。
2. 今日已得积分。
3. 今日剩余次数。
4. 小游戏入口。
5. 签到任务入口。
6. 会员解锁更多次数提示。

### 5.2 功能验收

1. 用户可以完成石头剪刀布游戏。
2. 每局结束后发放积分。
3. 每局发放积分有明细。
4. 用户达到每日任务次数后，不能继续获得积分。
5. 达到次数后提示开通会员或明日再来。
6. 会员用户每日任务次数高于普通用户。
7. 广告加倍成功后积分增加。
8. 同一局游戏不能重复发积分。

## 6. 我的页验收

### 6.1 页面验收

必须显示：

1. 用户信息。
2. 我的积分。
3. 可兑换金额。
4. 可提现积分。
5. 冻结积分。
6. 已提现或累计提现。
7. 立即提现按钮。
8. 会员权益卡。
9. 我的收益入口。
10. 会员中心入口。
11. 在线客服入口。
12. 邀请好友入口。

### 6.2 文案验收

会员权益卡推荐文案：

> 开通后解锁更多积分任务、影视高清权益、邀请奖励和提现权益。

不应出现强承诺文案：

1. 充值必回本。
2. 每天稳赚。
3. 看广告赚钱。
4. 最高每天 100 元。

## 7. 会员验收

1. 能展示月卡、季卡、年卡。
2. 价格为配置值，默认 19.9、49.9、99.9。
3. 能展示会员权益。
4. 能判断当前用户是否会员。
5. 会员过期时间能展示。
6. 会员开通后权益即时生效。
7. 会员签到、任务次数、提现门槛等权益能生效。
8. 会员支付可 mock，但必须保留真实支付回调接口。

## 8. 邀请验收

1. 用户能看到邀请码或邀请链接。
2. 用户能复制邀请话术。
3. 新用户通过邀请码进入可绑定上级。
4. 不能自邀请。
5. 用户只能绑定一次上级。
6. 能展示邀请人数。
7. 能展示邀请 3 人/5 人解锁进度。
8. 好友开通会员后能产生返利积分记录。
9. 返利积分默认进入冻结状态。
10. 返利不能重复发放。

## 9. 影视页验收

1. 能正常浏览影视资源列表。
2. 能按分类切换：我的订阅、番剧片库、最新电影、4K 影视。
3. 能搜索资源。
4. 能复制百度/夸克链接。
5. 免费用户复制前有互动或广告校验。
6. 会员用户享有直接复制或更多复制次数。
7. 可配置积分免广告复制。
8. “订阅”类按钮不再含糊，需改为“解锁高清/加入片单/追更提醒”等明确文案。
9. 资源加载失败有兜底提示。

## 10. 视频下载验收

1. 首页视频解析功能保留。
2. 用户可粘贴视频分享链接或文案。
3. 解析成功后可下载/保存。
4. 免费用户下载前有互动或广告流程。
5. 会员用户可直接下载或更多次数。
6. 抖音等失败场景要有明确失败提示。
7. 失败时提供重试、反馈、去任务、去影视等入口。
8. 不要求本阶段接入视频号。

## 11. 提现验收

1. 用户能查看可提现积分和可提现金额。
2. 不满足门槛时不能提现。
3. 满足门槛时能提交提现申请。
4. 提交后生成提现记录。
5. 提现状态至少包括待审核、已通过、已驳回、已打款。
6. 提现申请后对应积分冻结或扣减。
7. 提现驳回后积分退回。
8. 自动打款不是本阶段必须项。

必须记录以下事件或日志：

1. app_open。
2. tab_click。
3. checkin_success。
4. checkin_ad_bonus_success。
5. game_start。
6. game_complete。
7. reward_ad_show。
8. reward_ad_complete。
9. media_view。
10. media_copy_click。
11. video_parse_start。
12. video_parse_success。
13. video_parse_failed。
14. member_page_view。
15. member_purchase_success。
16. invite_page_view。
17. invite_bind_success。

- 正式环境应进入埋点表或统计系统。

## 13. Mock 验收

允许 mock：

1. 会员支付成功。
2. 提现打款。
3. 邀请海报。
4. 新游戏占位。
5. 后台统计面板。

不允许只 mock：

1. 积分账户。
2. 积分明细。
3. 签到防重复。
4. 游戏任务防重复。
5. 提现申请记录。
6. 邀请绑定关系。

## 14. 上线前检查清单

1. 是否有明显报错。
2. 是否影响原有视频下载功能。
3. 是否影响原有影视列表功能。
4. 是否能正常登录或识别用户。
5. 是否能完成签到。
6. 是否能完成游戏任务。
7. 是否能查看积分资产。
8. 是否能提交提现申请。
9. 是否能进入会员页。
10. 是否能进入邀请页。
11. 是否所有积分变化都有明细。
12. 是否有重复发积分风险。
13. 是否有明显诱导高收益文案。
14. 是否所有关键规则可配置。



## 补充验收：微信静默登录

| 验收项 | 标准 | 是否 P0 |
|---|---|---|
| 静默登录 | 新用户首次打开小程序无需授权头像昵称即可进入 | 是 |
| 自动建档 | 新用户首次登录后自动创建用户、积分账户、邀请码 | 是 |
| 邀请绑定 | 通过邀请链接进入的新用户，登录后能绑定上级 | 是 |
| 登录安全 | AppSecret 和 session_key 不出现在前端代码 | 是 |
| 接口鉴权 | 积分、签到、任务、会员、邀请、提现接口均基于 token 获取 user_id | 是 |
| 默认资料 | 未授权头像昵称时展示默认头像和默认昵称 | 是 |

## 补充验收：非会员可见会员任务

| 验收项 | 标准 | 是否 P0 |
|---|---|---|
| 非会员任务 | 普通用户每日可完成 10 次互动任务 | 是 |
| 会员任务展示 | 非会员可看到会员每日 100/150/200 次任务权益，但不能执行超出普通权限的任务 | 是 |
| 会员权益差异 | 首页、游戏页、会员中心能看到普通与会员权益差异 | 是 |
| 文案边界 | 前台表达为“更多积分任务/更多互动任务”，不承诺固定收益或回本 | 是 |
