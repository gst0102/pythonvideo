# codex-prompt.md

你是 Codex，请在当前 Git 仓库中执行悦享互动宝 MVP v0.1 改造任务。

## 1. 项目背景

项目名称：悦享互动宝。

项目类型：微信小程序。

一句话定位：

> 悦享互动宝是一个面向泛娱乐和轻量工具用户的微信小程序，通过视频提取、影视福利、互动小游戏和积分任务，为用户提供工具与资源权益，并通过广告、会员和邀请实现商业化变现。

当前已有四个 Tab：

1. 首页：视频提取。
2. 影视：影视资源。
3. 游戏：休闲小游戏。
4. 我的：余额、积分、会员、邀请、提现。

当前阶段目标：

> 把积分作为主线，把签到作为每日入口，把游戏作为任务中心，把影视作为拉新钩子，把会员和邀请作为变现杠杆。

## 2. 执行前必须先做

在修改代码前，请先完成项目结构识别：

1. 扫描仓库目录。
2. 找到微信小程序前端目录。
3. 找到后端服务目录。
4. 找到首页、影视、游戏、我的四个页面文件。
5. 找到当前已有接口、数据模型、配置文件。
6. 找到广告、会员、提现、邀请、积分相关已有代码。
7. 输出你识别到的关键路径，再开始修改。

不要在不了解目录结构的情况下新建一套完全独立代码。

## 2.1 开发方式要求

本次必须在当前原有项目内做渐进式改造。

请先学习老项目结构和现有实现，再按阶段二文档修改。不要另起一个脱离当前项目的新项目文件夹重写。

允许在原项目内新增模块、页面组件、配置文件和数据表；如改动较大，可在原仓库中新建分支或新建 v2 页面目录，但仍要复用原项目的微信小程序配置、登录、广告、支付、视频解析、影视资源等已有能力。

当涉及页面美化、小游戏 UI、邀请返利弹窗、积分动效、会员页视觉优化时，请读取并遵守：

`skills/ui-beautify/SKILL.md`

## 2.2 微信静默登录要求

项目采用微信小程序静默登录优先策略。

1. 前端调用 `wx.login()` 获取 code。
2. 后端通过 `code2Session` 换取 openid。
3. 后端基于 openid 查找或创建系统用户。
4. 首次创建用户时自动初始化积分账户、邀请码和新人任务状态。
5. MVP 阶段不强制获取头像、昵称、手机号。
6. 默认昵称使用“悦享用户xxxx”，默认头像使用系统默认头像。
7. 如果启动参数存在 `invite_code`，登录时传给后端，由后端绑定邀请关系。
8. 用户不能绑定自己，不能重复绑定上级。
9. AppSecret 和 session_key 只能在后端使用，不能出现在前端代码。
10. 所有积分、签到、任务、会员、邀请、提现接口必须从 token 解析 user_id，不能信任前端传入 user_id。

## 6. 产品规则 v0.1

### 6.1 积分

前台统一展示“积分”。

默认：

- 100 积分 = 1 元。

后台需要区分：

1. 总积分。
2. 可提现积分。
3. 冻结积分。
4. 消耗积分。
5. 已提现积分。

所有积分变动必须写明细。

### 6.2 签到

默认规则：

- 普通用户每日签到 1 积分。
- 会员每日签到 2 积分。
- 看广告可额外加积分。
- 连续 3 天/7 天可给额外奖励。
- 同一天不能重复签到。

### 6.3 游戏任务

默认规则：

- 普通用户每日 10 次积分任务。
- 月卡会员每日 100 次积分任务。
- 季卡会员每日 150 次积分任务。
- 年卡会员每日 200 次积分任务。
- 非会员可以看到会员任务入口和权益差异，但不能执行超出普通用户权限的任务。
- 每局发放 1–2 积分。
- 看广告可加倍。
- 同一局不能重复发积分。

当前保留石头剪刀布游戏，后续游戏只做预留，不要重做复杂游戏。

### 6.4 会员

当前价格：

- 月卡：19.9 元。
- 季卡：49.9 元。
- 年卡：99.9 元。

会员权益文案：

> 开通后解锁更多积分任务、影视高清权益、邀请奖励和提现权益。

会员权益包括：

1. 更多每日积分任务。
2. 签到积分加成。
3. 小游戏互动次数增加。
4. 提现门槛降低。
5. 提现手续费减免或降低。
6. 影视高清/4K 权益。
7. 视频下载免广告或更多次数。
8. 邀请好友奖励加成。
9. 开通会员赠积分。

### 6.5 邀请

默认规则：

1. 邀请注册得积分。
2. 邀请 3 人解锁高清资源。
3. 邀请 5 人解锁 4K 资源。
4. 好友开通会员后按比例返积分。
5. 一级返利 50%。
6. 二级返利 5%。
7. 返利积分默认冻结 7 天。

### 6.6 提现

默认规则：

1. 新人首提 1 元。
2. 普通用户后续 5 元起提。
3. 会员 1 元起提。
4. 提现默认人工审核。
5. 自动打款不是本次必做。
