# 01-product-plan.md

## 1. 项目概述

项目名称：悦享互动宝

项目类型：微信小程序

当前阶段：阶段二 v0.1 文档/任务生成

一句话定位：

> 悦享互动宝是一个面向泛娱乐和轻量工具用户的微信小程序，通过视频提取、影视福利、互动小游戏和积分任务，为用户提供工具与资源权益，并通过广告、会员和邀请实现商业化变现。

阶段性定位：

> 工具入口 + 影视福利 + 互动积分任务的微信小程序。

## 2. MVP 唯一目标

MVP 的唯一目标是：

> 验证“工具/影视入口 + 积分任务 + 会员权益 + 邀请裂变”是否能带来有效用户、广告收益、会员转化和次日留存。

本阶段不是做综合工具箱，也不是做完整游戏小程序，而是把现有互动宝整理成一个可以推广、可以测数据、可以验证商业模型的小程序版本。

## 2.1 补充决策：开发方式与登录策略

### 2.1.1 开发方式

本次阶段二改造应在原有 `pythonvideo` 项目内进行渐进式修改，不建议另起一个完全独立项目重写。

原因：

1. 当前悦享互动宝已经上线，已有微信小程序配置、流量主、视频解析、影视资源、会员、提现、邀请等基础能力。
2. 重新开发会增加登录、支付、广告、接口、审核、线上迁移成本。
3. MVP 目标是验证“积分任务 + 会员 + 邀请 + 影视/工具入口”模型，而不是重建技术架构。
4. Codex 应先学习老项目结构，在老项目中新建或修改必要模块。

允许的代码组织方式：

- 在原项目中新增 `points`、`checkin`、`tasks`、`invite`、`withdraw` 等模块。
- 在原有四个 Tab 页面上渐进改造。
- 如改动较大，可在原仓库中新建分支或新建 `v2` 页面目录做迁移，但不要另起一个脱离老项目的新仓库。

### 2.1.2 微信登录策略

MVP 阶段采用微信小程序静默登录优先策略。

用户首次进入小程序后，前端调用 `wx.login()` 获取临时 `code`，后端通过微信 `code2Session` 换取 `openid`，并基于 `openid` 自动创建系统用户、积分账户和邀请码。

MVP 阶段不强制获取用户头像、昵称和手机号。系统使用默认昵称和默认头像，例如“悦享用户1234”。用户可在后续主动完善资料。

签到、小游戏积分任务、广告奖励、邀请绑定、影视资源权益、视频下载权益等功能，均基于静默登录后的系统 token 执行。

提现、支付、客服、资料完善等场景，可以后置引导用户补充必要信息。

### 2.1.3 非会员与会员任务展示

非会员可以看到会员权益和会员任务入口，但只能完成普通用户每日任务次数。

默认配置：

- 普通用户每日互动任务：10 次。
- 月卡会员每日互动任务：100 次。
- 季卡会员每日互动任务：150 次。
- 年卡会员每日互动任务：200 次。

非会员在游戏页、首页今日福利卡和会员中心均可看到会员权益差异。

前台表达为“更多互动任务”“更多积分任务”“会员解锁更多次数”，不得表达为固定收益或承诺回本。


## 3. 目标用户

### 3.1 核心用户

1. 泛娱乐资源用户
   - 需要番剧、影视、最新电影、高清/4K 网盘资源。
   - 愿意完成互动、观看广告或邀请好友解锁资源。

2. 积分福利用户
   - 对签到、小游戏、积分任务、提现、兑换、邀请奖励感兴趣。
   - 包括大学生、普通微信群用户、碎片时间用户、轻度羊毛用户。

3. 短视频工具用户
   - 需要短视频链接解析、下载、素材保存。
   - 包括短视频创作者、自媒体运营者、剪辑用户。

### 3.2 非 MVP 优先用户

1. 专业金融/股票用户。
2. 车主加油/油价刚需用户。
3. 重度游戏玩家。
4. 大规模羊毛群用户。

## 4. 核心产品判断

当前互动宝已有 4 个 Tab：

1. 首页：视频提取。
2. 影视：影视资源。
3. 游戏：休闲小游戏。
4. 我的：余额、积分、会员、邀请、提现。

当前问题：

1. 首页过度工具化，缺少今日福利/积分承接。
2. 影视页可作为拉新钩子，但和积分、邀请、会员绑定不足。
3. 游戏页目前像单个小游戏，不像互动任务中心。
4. 我的页有余额、积分、收入等多个概念，用户理解成本较高。
5. 缺少签到入口和新人首日路径。
6. 缺少统一的积分主线。

本阶段核心改造：

> 把积分作为主线，把签到作为每日入口，把游戏作为任务中心，把影视作为拉新钩子，把会员和邀请作为变现杠杆。

## 5. MVP 范围

### 5.1 本阶段必须做

1. 首页增加今日福利/签到积分卡。
2. 增加每日签到积分能力。
3. 游戏页升级为互动任务中心。
4. 我的页统一积分表达。
5. 会员权益重新包装为“更多积分任务 + 影视/下载权益 + 邀请奖励 + 提现权益”。
6. 邀请好友规则展示与邀请入口优化。
7. 影视页按钮与权益文案优化。
8. 视频下载失败兜底。
9. 建立积分明细、签到记录、任务记录、邀请记录、提现记录等基础数据结构。
10. 增加 MVP 数据埋点。

### 5.2 本阶段可以做，但不是必须

1. 影视资源消耗积分免广告复制。
2. 会员每日免费复制影视资源次数。
3. 邀请 3 人/5 人解锁高清/4K 权益。
4. 签到连续 3/7 天奖励。
5. 新人任务弹窗。
6. 邀请海报。

### 5.3 本阶段明确不做

1. 油价、股票、银行利率、附近加油站等泛工具。
2. 独立游戏小程序。
3. 斗地主、棋牌对战等重型游戏。
4. 复杂等级系统。
5. 复杂积分商城。
6. 自动化大额提现。
7. 承诺固定回本周期。
8. 明示“看广告赚钱”“充值回本”“每天最高赚 100 元”等高预期话术。

## 6. 页面规划

### 6.1 首页

定位：承接入口 + 视频工具 + 今日福利。

模块：

1. 今日福利卡：展示当前积分、签到状态、今日可领。
2. 视频下载助手：粘贴链接、开始解析、解析结果、广告/会员下载。
3. 热门入口：影视福利、互动任务、邀请好友。
4. 下载失败兜底入口。

推荐首屏文案：

> 今日福利  
> 签到领积分，互动任务领更多。

### 6.2 影视页

定位：拉新钩子 + 资源权益。

模块：

1. 我的订阅。
2. 番剧片库。
3. 最新电影。
4. 4K 影视。
5. 搜索框。
6. 资源列表。
7. 复制百度链接。
8. 复制夸克链接。
9. 解锁高清/追更提醒。
10. 邀请好友解锁。

文案调整：

- “订阅”改为“解锁高清”“加入片单”或“追更提醒”。
- “复制资源前，免费用户需要完整观看激励广告”改为“完成互动后可复制资源”。

### 6.3 游戏页

定位：互动任务中心。

模块：

1. 今日互动奖励。
2. 今日已得积分。
3. 今日剩余次数。
4. 签到任务。
5. 小游戏入口。
6. 看广告加倍。
7. 会员解锁更多互动机会。

当前游戏：石头剪刀布。

后续可扩展：猜数字、每日答题、幸运翻牌、2048 简版。

### 6.4 我的页

定位：积分资产 + 会员 + 邀请 + 提现。

模块：

1. 用户信息。
2. 我的积分。
3. 可兑换金额。
4. 可提现积分。
5. 冻结积分。
6. 立即提现。
7. 会员权益卡。
8. 我的收益。
9. 会员中心。
10. 在线客服。
11. 邀请好友。

## 7. 核心用户路径

### 7.1 新用户首日路径

1. 用户进入小程序。
2. 首页看到“今日福利/签到积分”。
3. 完成签到，获得积分。
4. 进入游戏页玩一局，获得积分。
5. 看广告加倍或领取奖励。
6. 查看影视页资源，复制资源或解锁高清。
7. 进入我的页查看积分和可兑换金额。
8. 被引导开通会员或邀请好友。

### 7.2 影视拉新路径

1. 用户通过社群看到影视资源话术。
2. 进入影视页搜索/浏览资源。
3. 完成互动后复制网盘链接。
4. 为解锁高清/4K 邀请好友。
5. 新用户进入后被引导签到、玩游戏、开会员。

### 7.3 工具路径

1. 用户进入首页粘贴短视频链接。
2. 系统解析视频。
3. 免费用户完成互动/广告后下载。
4. 会员用户直接下载或享有更多次数。
5. 下载失败时进入兜底路径：重试、反馈、进入影视/游戏领取积分。

### 7.4 会员转化路径

1. 用户通过签到/小游戏/影视功能获得积分。
2. 用户看到会员可解锁更多积分任务、高清权益、提现权益、邀请奖励。
3. 用户开通会员。
4. 会员每日完成更多任务，并邀请好友。

## 8. 关键商业规则

### 8.1 积分规则 v0.1 假设

如未另行配置，默认采用：

> 100 积分 = 1 元可兑换金额。

积分来源：

1. 签到。
2. 游戏任务。
3. 看广告加倍。
4. 邀请好友。
5. 好友开会员返积分。
6. 会员开通赠积分。
7. 影视/下载任务奖励。

积分用途：

1. 提现。
2. 兑换资源权益。
3. 兑换下载权益。
4. 兑换游戏次数。
5. 兑换提现手续费减免券。

前台统一展示积分；后台区分总积分、可提现积分、冻结积分、消耗积分和已提现积分。

### 8.2 会员规则 v0.1 假设

当前价格：

- 月卡：19.9 元。
- 季卡：49.9 元。
- 年卡：99.9 元。

会员权益：

1. 更多每日积分任务。
2. 签到积分加成。
3. 小游戏互动次数增加。
4. 提现门槛降低。
5. 提现手续费减免或降低。
6. 影视高清/4K 权益。
7. 视频下载免广告或更多次数。
8. 邀请好友奖励加成。
9. 开通会员赠积分。

### 8.3 邀请规则 v0.1 假设

1. 邀请注册得积分。
2. 邀请 3 人解锁高清资源。
3. 邀请 5 人解锁 4K 资源。
4. 好友开通会员后按比例返积分。
5. 一级会员返利：默认 50%。
6. 二级会员返利：默认 5%。
7. 邀请返利进入冻结积分，冻结期默认 7 天。

### 8.4 提现规则 v0.1 假设

1. 100 积分 = 1 元。
2. 新人首提门槛：1 元。
3. 后续提现门槛：普通用户 5 元，会员 1 元。
4. 提现需要人工审核。
5. 提现申请后展示到账周期。
6. 每日提现上限后台可配置，不在前台强宣传。

## 9. 推广策略 v0.1

### 9.1 三套推广入口

1. 影视福利入口
   - 适合大学生群、影视兴趣群、普通微信群。
   - 核心话术：热播资源每日更新，高清资源可解锁。

2. 视频工具入口
   - 适合短视频创作者群、剪辑群、自媒体群。
   - 核心话术：短视频链接解析，支持多平台下载。

3. 积分互动入口
   - 适合大学生群、普通微信群、轻度福利用户。
   - 核心话术：每日互动领积分，新人可体验兑换。

### 9.2 推广优先级

P0：大学生群、普通微信群、影视兴趣群。

P1：短视频创作者群、自媒体群。

P2：羊毛群、兼职副业群。

羊毛群不作为首批大规模推广渠道。
