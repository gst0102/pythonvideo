# 悦享互动宝阶段二文档包 v0.1

本目录为“悦享互动宝”阶段二文档/任务生成交付物，可直接交给 Codex 或开发人员执行。

## 1. 项目定位

悦享互动宝是一个面向泛娱乐和轻量工具用户的微信小程序，通过视频提取、影视福利、互动小游戏和积分任务，为用户提供工具与资源权益，并通过广告、会员和邀请实现商业化变现。

阶段性定位：

> 工具入口 + 影视福利 + 互动积分任务的微信小程序。

## 2. 本阶段目标

MVP v0.1 唯一目标：

> 验证“工具/影视入口 + 积分任务 + 会员权益 + 邀请裂变”是否能带来有效用户、广告收益、会员转化和次日留存。

本阶段不是做综合工具箱，也不是做独立游戏小程序。

## 4. MVP 必做范围

P0 功能：

1. 首页增加今日福利/签到积分卡。
2. 增加每日签到积分能力。
3. 游戏页升级为互动任务中心。
4. 我的页统一积分表达。
5. 会员权益重新包装。
6. 邀请好友基础链路优化。
7. 影视页按钮和权益文案优化。
8. 视频下载失败兜底。
9. 新增积分明细记录。
10. 新增提现申请和提现记录基础能力。
11. 新增关键埋点或事件日志。

## 5. 明确不做范围

本阶段不做：

1. 油价、股票、银行利率、附近加油站。
2. 独立游戏小程序。
3. 斗地主、棋牌对战等重型游戏。
4. 复杂等级系统。
5. 复杂积分商城。
6. 自动大额提现。
7. 承诺收益、回本、稳赚等前台文案。
8. 全量重构旧代码。

## 6. 核心产品原则

1. 前台统一使用“积分”作为用户理解主概念。
2. 后台需要区分总积分、可提现积分、冻结积分、消耗积分和已提现积分。
3. 签到是每日回访入口。
4. 游戏页是互动任务中心，不只是单个小游戏页面。
5. 影视页是拉新钩子，需要和邀请/会员/积分绑定。
6. 首页需要兼顾视频下载和今日福利承接。
7. 会员权益必须具体，不能只写虚权益。
8. 邀请好友需要任务化和进度化。

## 7. 默认业务规则 v0.1

积分：

- 默认 100 积分 = 1 元。

签到：

- 普通用户每日签到 1 积分。
- 会员每日签到 2 积分。
- 看广告可额外加积分。
- 连续 3/7 天可给额外奖励。

游戏任务：

- 普通用户每日 10 次积分任务。
- 会员用户每日 100 次积分任务。
- 每局 1–2 积分。
- 看广告可加倍。

会员：

- 月卡 19.9 元。
- 季卡 49.9 元。
- 年卡 99.9 元。

邀请：

- 邀请注册得积分。
- 邀请 3 人解锁高清。
- 邀请 5 人解锁 4K。
- 一级会员返利 50%。
- 二级会员返利 5%。
- 返利冻结期默认 7 天。

提现：

- 新人首提 1 元。
- 普通用户后续 5 元起提。
- 会员 1 元起提。
- 提现默认人工审核。

## 9. Codex 执行建议

建议直接将 `codex-prompt.md` 发给 Codex。

Codex 执行前必须先扫描项目结构，不要盲目新建一套代码。

执行顺序建议：

1. 识别项目结构。
2. 实现数据结构和配置。
3. 实现积分账户与明细。
4. 实现签到。
5. 改造首页。
6. 改造游戏页。
7. 改造我的页。
8. 改造会员与邀请。
9. 改造影视权益。
10. 增加提现和埋点。
11. 按 `04-acceptance.md` 验收。

## 10. 关键验收

完成后至少满足：

1. 用户进入首页能看到今日福利/签到。
2. 用户能签到并获得积分。
3. 用户能玩石头剪刀布并获得积分。
4. 用户能查看统一积分资产。
5. 用户能查看会员权益。
6. 用户能邀请好友。
7. 用户能提交提现申请。
8. 用户能浏览影视资源并复制资源。
9. 视频解析失败有兜底路径。
10. 所有积分变化有明细。
11. 不出现强收益承诺文案。

## 11. 后续阶段

本阶段完成后，根据数据决定是否进入：

1. 互动宝运营测试阶段。
2. 独立游戏小程序阶段一深度讨论。
3. 更多游戏接入。
4. 积分商城/权益兑换扩展。
5. 完整后台和数据看板建设。



## 补充关键决策

1. 本阶段在原有 `pythonvideo` 项目内渐进式改造，不另起独立项目重写。
2. Codex 执行前必须先扫描老项目，识别现有页面、接口、数据结构、广告、支付、会员、提现、邀请能力。
3. 微信登录采用静默登录优先，默认通过 `wx.login + code2Session + 后端 token` 自动建档。
4. MVP 阶段不强制获取头像、昵称、手机号。
5. 非会员可以看到会员任务和权益差异，但每日只允许完成普通任务次数。
6. 默认任务次数：普通 10 次，月卡 100 次，季卡 150 次，年卡 200 次。
