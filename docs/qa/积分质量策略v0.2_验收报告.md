## 3. 已覆盖测试项

- Python 编译检查通过。
- 后端核心模块导入通过。
- 小程序构建通过。
- `git diff --check` 通过。
- 数据库升级到 `017_netdisk_points_quality_strategy`。
- 推荐排序接口返回 `quality_score/uploader_credit_level/valid_days`。
- P0 联调验证：
  - 普通资源：下载者 -5，上传者 +1，平台回收 4。
  - 精选资源：下载者 -10，上传者 +2，平台回收 8。
  - 重复解锁不重复扣分、不重复分成。
  - 单资源每日上传者分成合计 10 分封顶。
  - 短期失效后资源隐藏、失效数增加、信用降低、积分可为负。
  - 负积分用户上传被拦截。

## 5. 发现的问题

- 本地历史库缺少 `alembic_version`，已按现有 016 表结构 stamp 到 016 后升级 017。
- `alembic_version.version_num` 默认 32 位不足以保存本项目长 revision id，本地已扩展到 `varchar(128)`。
- Sass `@import` 仍有废弃警告，但不阻断小程序构建。
