# 当前项目测试清单与验收标准 v1

## 1. 功能核心目标总结

本次改造的核心目标，是把原先“广告完成后立即按固定规则发放积分”的模式，重构为“签到固定到账、小游戏先展示预估积分、次日下午按真实 eCPM 结算昨日积分、缺失真实数据时按近 7 日均值兜底、后补真实数据只做差额调整”的结算体系。

本次交付必须同时满足以下业务目标：

1. 用户能清晰区分`今日预估积分`、`昨日已结算积分`、`累计积分`、`已提现金额`、`可提现/冻结积分`。
2. 签到积分继续按固定规则实时到账，不受 eCPM 日结改造影响。
3. 小游戏积分必须建立在“完成任务 + 完成广告观看”的前提下，只先发放`预估积分`，不得直接当作已结算可提现积分。
4. 系统必须支持 D+1 下午按昨日真实广告数据结算；若运营未录入，则 D+2 自动按近 7 日平均 eCPM 兜底结算。
5. 若真实数据在兜底后补录，系统只能生成一次`差额调整`，不得覆盖历史展示或重复补差。
6. 首页、我的资产、积分流水、后台结算页、提现口径必须统一，确保预估、已结算、调整、冻结、提现数据一致。
7. 会员档位系数、邀请返利、二级分销、广告统计、支付返利等高风险逻辑不得因本次改造失真或重复发放。

## 2. 测试范围

本次测试范围包括：

- 首页收益概览
- 我的资产 / 积分页 / 提现页
- 签到面板
- 小游戏任务与广告完成链路
- 预估积分生成逻辑
- D+1 真实 eCPM 结算
- D+2 近 7 日均值兜底结算
- 真实数据后补差额调整
- 积分流水与账户口径一致性
- 会员档位系数与配置生效规则
- 邀请奖励 / 二级分销收益
- 广告曝光、点击、完成等后台统计
- 后台手工录入与结算执行
- 提现冻结 / 提现成功 / 驳回退回
- 幂等、防重、防刷、历史数据隔离

## 4. P0 高风险清单

以下问题必须按 P0 处理，未验证通过前不得判定可上线：

1. `积分口径风险`：预估积分、已结算积分、可提现积分、冻结积分、累计积分之间无法对账。
2. `重复发放风险`：同一局小游戏因重复点击、重复请求、页面刷新、任务重试而重复生成预估积分。
3. `广告完成校验风险`：广告未完整观看却仍可拿到任务预估积分。
4. `结算重复风险`：D+1 真实数据结算、D+2 兜底结算、后补真实数据差额调整出现重复执行。
5. `补差错误风险`：同一日真实数据补录多次，导致差额调整重复发放或重复扣减。
6. `会员系数错误风险`：普通/月卡/季卡/年卡积分系数或每日次数使用错误，导致收益异常。
7. `历史污染风险`：后台修改会员配置或结算配置后，历史已结算数据被重算、覆盖或漂移。
8. `邀请奖励风险`：一级邀请奖励、二级分销收益未按新结算口径正确发放，或发生重复返利、串级返利。
9. `广告统计风险`：曝光、完成、点击、eCPM、收入统计错误，导致结算基础数据失真。
10. `支付/返利风险`：会员支付成功但权益未生效，支付失败却开权益，重复支付回调导致重复赠送、重复返利。
11. `提现口径风险`：用户可把预估积分当作已结算积分提现，或冻结/成功/退回口径不一致。
12. `前后台不一致风险`：首页、我的资产、积分流水、后台结算页、后台统计页显示不一致。

## 5. 验收标准

满足以下条件，方可判定本次改造达到开发验收标准：

1. 签到积分链路完整可用，且不受 eCPM 改造影响。
2. 小游戏完成后只有在广告完整播放成功时，才生成一次且仅一次预估积分。
3. 预估积分与已结算积分在前端展示和账务口径上严格分离。
4. D+1 真实数据结算可正常执行；D+2 近 7 日平均 eCPM 兜底可正常执行，且不重复。
5. 真实数据后补时只生成一次差额调整，不覆盖历史展示。
6. 会员档位次数和积分系数按配置正确生效，且仅影响未来任务/未来结算。
7. 一级邀请奖励、二级分销收益、会员购买、提现冻结/成功/退回等周边高风险链路与新积分模型兼容。
8. 首页、我的资产、积分流水、后台结算页、后台统计页可完成逐项对账。
9. 不存在可通过刷新、重放请求、重复回调、重复任务提交刷积分或刷收益的漏洞。
10. P0 项全部通过；若任一 P0 未覆盖或失败，则本次验收不得给出“通过”结论。

每次涉及本模块开发、修复或上线前，至少执行以下回归：

1. 首页收益概览：今日预估、昨日已结算、累计积分展示正确。
2. 我的资产：累计、可提现、冻结、已提现口径一致。
3. 签到：首次签到到账、重复签到拦截、连签奖励正确。
4. 小游戏：成功完成 + 广告完成后发预估；失败或广告未完成不发放。
5. 小游戏幂等：重复点击、刷新、重放请求不重复发积分。
6. D+1 真实 eCPM 结算：真实数据录入后结算结果正确。
7. D+2 兜底结算：缺数据时按近 7 日平均值结算且只执行一次。
8. 差额调整：真实数据补录后只补差一次，不覆盖历史。
9. 会员档位：四档系数、每日次数、前端权益说明正确。
10. 邀请奖励：一级邀请和二级分销收益正确到账且不重复。
11. 邀请绑定：禁止自邀、禁止重复绑定邀请人。
12. 广告统计：曝光、完成、点击、eCPM、收入与实际行为一致。
13. 提现链路：仅已结算积分可提现，冻结/成功/驳回口径正确。
14. 支付回调：会员开通成功、失败不生效、重复回调不重复生效。
15. 文案巡检：不误导用户“预估即实际到账”，不得出现高风险收益承诺。
