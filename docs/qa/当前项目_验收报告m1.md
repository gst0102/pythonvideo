## 5. 需要开发 Codex 修复的 Bug 单

### BUG-M1-001：网盘筛选仅静态高亮，未实现真实 mock 筛选

【严重级别】
P1

【所属模块】
首页 / 资源列表 / 网盘筛选

【复现步骤】
1. 打开 `video-ts` 小程序资源首页。
2. 点击“全部、夸克、百度、迅雷、阿里”等网盘筛选标签。
3. 观察资源列表是否根据网盘类型变化。

【实际结果】
根据自测报告，当前仅确认标签展示和高亮，仍为静态 mock，未实现真实筛选逻辑。

【预期结果】
点击不同网盘标签后，资源列表应按 mock 数据中的网盘类型过滤；如某标签无资源，应展示空状态或明确提示。

【可能原因】
当前原型重点完成主流程，筛选状态仅用于 UI 高亮，未绑定资源列表过滤计算。

【建议修复方向】
1. 在首页资源列表中维护当前选中的 pan 标签。
2. 基于 mock resources 的 pan 字段过滤展示。
3. 保留“全部”展示全部资源。
4. 无结果时展示空状态，不白屏。

【开发 Codex 执行指令】
请修复首页网盘筛选逻辑，只修改 netdisk 首页和必要 mock 相关代码，不要改动后端、支付、邀请、提现逻辑。修复后运行 `npm run type-check`，并在自测报告中补充筛选用例结果。

【修复后必须回归】
1. 首页默认展示全部资源。
2. 点击夸克只展示夸克资源。
3. 点击百度只展示百度资源。
4. 点击无资源标签展示空状态。
5. 未解锁资源卡片仍不泄露链接。

【验收标准】
网盘筛选可实际影响 mock 资源列表，切换稳定，无白屏，且不泄露资源链接。

### BUG-M1-002：异常 storage 场景缺少容错验证

【严重级别】
P1

【所属模块】
本地 mock 状态 / 收藏 / 任务 / 上传 / 补链

【复现步骤】
1. 在微信开发者工具或浏览器调试环境中手动写入异常 storage 值。
2. 重新打开收藏页、赚积分页、上传页、补链页。
3. 观察页面是否白屏或报错。

【实际结果】
自测报告说明正常 storage 读写已覆盖，但未模拟破坏 storage 的异常值场景。

【预期结果】
storage 异常时页面应降级为默认 mock 状态，不白屏、不报错、不影响其他页面。

【可能原因】
当前本地 mock 读取逻辑可能假设 storage 数据结构总是正确。

【建议修复方向】
1. 为读取 storage 的位置增加类型判断和兜底默认值。
2. 对数组、对象、状态枚举做安全校验。
3. 异常时清理对应 key 或回退默认 mock 数据。

【开发 Codex 执行指令】
请补充 netdisk mock 本地 storage 读取的容错处理，并补充手工验证说明。不要扩大修改范围，不要改后端。

【修复后必须回归】
1. 正常收藏状态可读写。
2. 正常任务状态可读写。
3. 上传/补链记录可读写。
4. storage 被破坏后页面不白屏。
5. 清空 storage 后页面恢复默认 mock 状态。

【验收标准】
任意 netdisk 相关 storage key 为空、类型错误、字段缺失时，页面均能正常展示默认状态。

## 7. 回归测试清单

本轮修复或人工确认后，必须回归：

- 首页可打开，资源卡不泄露链接。
- 网盘筛选切换正常，列表和空状态正确。
- 底部 tab：资源、求资源、赚积分、收藏、我的均可访问。

- 求资源发布必填校验、悬赏积分 5-50、提交后保存本地 mock。
- 求资源“提交资源”入口跳转符合产品预期。

- 补链/投诉必填校验，提交后为待审核，不直接替换链接或发奖励。
- 赚积分任务 claimable/completed/limited 状态正确，重复点击不能重复领取。
- 上传/补链任务与任务中心状态联动正常。
- 我的页不进入旧收益/提现/二级分销页面，不出现高风险收益承诺。
- 清空或破坏 storage 后页面不白屏。

- 资源详情接口未解锁不返回敏感链接字段。
