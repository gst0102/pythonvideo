# 网盘审核释放与失效处罚_测试清单与验收标准

## 功能目标

补齐网盘资源上传/补链后的审核闭环：

- 审核通过后，冻结积分释放为可用积分。
- 拒绝或确认失效后，扣回冻结奖励；如果奖励已释放，则从可用积分处罚。
- 投诉超过阈值后先隐藏资源，避免继续消耗用户积分。
- 后台提供上传、补链、投诉列表与通过、拒绝、确认失效操作入口。
- 积分流水 `idempotency_key` 有唯一约束，重复操作不能重复释放或重复扣分。

## P0 风险点

- 重复点击审核通过导致可用积分重复增加。
- 审核拒绝或确认失效没有扣回冻结奖励。
- 奖励释放后确认失效，没有从可用积分中处罚。
- 投诉不奖励但误触发补链奖励。
- 投诉超过阈值后资源仍继续展示，导致用户继续扣积分获取失效资源。
- 积分流水唯一约束缺失，导致并发重复流水。

## 验收标准

- 上传/补链审核通过只释放一次冻结奖励。
- 拒绝/确认失效不会释放可用积分。
- 已释放奖励后确认失效会处罚可用积分，且不扣成负数。
- 投诉记录不奖励积分。
- 同一资源累计 3 条未驳回投诉后从资源列表隐藏。
- 后台接口可列表查看并执行通过、拒绝、确认失效。
- 所有积分变动都可在 `points_ledger` 中追踪，且幂等键唯一。

## 回归范围

- 上传资源冻结奖励。
- 补链冻结奖励。
- 投诉不奖励。
- 资源列表和详情可见性。
- 资源解锁扣可用积分。
- 我的页总积分、可用积分、待验证积分展示。
