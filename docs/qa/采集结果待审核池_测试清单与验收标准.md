# 采集结果待审核池 测试清单与验收标准

## 功能核心目标

把 LinuxDo 采集产生的低置信、疑似重复、新增网盘补充资源集中到后台待审核池，运营可以执行通过、跳过、合并，避免采集资源混入正式库或重复入库。

## 关键风险点

- P0：同一个候选重复点击“通过/合并”导致正式资源重复创建。
- P0：同链接或同标题同网盘重复资源被错误发布。
- P1：低置信资源无法区分，需要运营人工判断。
- P1：新增网盘补充资源不能被识别和合并。
- P1：已跳过资源仍反复出现在待处理池。

## 验收标准

- 待审核池能区分低置信、疑似重复、新增网盘补充。
- 通过/合并不会重复创建正式资源。
- 同链接、同标题同网盘候选不会被误发布。
- 跳过后不再出现在待审核列表。
- 后台提示全部中文。
