需要重点人工确认：

- 收藏页取消收藏后不会误删资源本身，只取消当前用户收藏关系。

## 7. 回归测试清单

- 我的页无 token 时不自动弹登录、不报错。
- 点击微信一键登录后，成功保存 token 并刷新用户资料和统计。
- 登录失败时展示错误，并可重新登录。
- 我的消息、我的投诉记录原入口仍可跳转。
- 我的上传空列表、正常列表、接口失败三种状态展示正常。
- 我的收藏空列表、正常列表、搜索无结果、取消收藏失败四种状态展示正常。
- 资源详情页收藏/取消收藏与收藏页列表状态一致。

- 确认 API base 不再使用线上不可访问的 `127.0.0.1` 后再真机或上线。
