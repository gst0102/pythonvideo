# 首页积分驱动入口_Codex自测报告

生成日期：2026-06-11
执行角色：开发 Codex

## 1. 本次修改目标

将 `netdisk` 首页从资源展示优先调整为积分经济入口优先，让用户首屏看到当前积分、今日可赚、邀请赚积分和充值积分，并保留搜索、网盘筛选、核心入口、分类、精选资源和热门悬赏。

本轮仍为静态原型，不接真实后端、不发起真实支付、不真实发放或扣减积分。

## 2. 修改文件列表

`video-ts`：

- `src/pages/netdisk/index.vue`
- `src/pages/netdisk/mock.ts`

`myproject`：

- `docs/qa/首页积分驱动入口_Codex自测报告.md`

## 3. 核心实现说明

- 首页标题改为 `悦享资源库`，副标题改为 `赚积分，换资源，找不到就悬赏`。
- 搜索框和网盘筛选仍保持在页面顶部。
- 网盘筛选后新增积分价值卡：
  - 当前积分 `100`。
  - 今日可赚 `54分`，由 `earnSummary.dailyCap - earnSummary.todayEarned` 得出。
  - `邀请赚积分` 跳转邀请页。
  - `充值积分` 跳转充值页。
- 新增 `快速入口`：
  - 找资源：停留当前首页资源列表。
  - 求资源：跳转发布求资源页。
  - 赚积分：跳转赚积分页。
  - 上传资源：跳转上传资源页。
- 分类区改为 `热门分类`，展示 5 个一级分类：
  - 影视娱乐
  - 学习办公
  - 自媒体素材
  - 本地生活
  - 软件工具
- 首页资源卡片减负：
  - 保留标题、网盘标签、资源等级、分类、积分、验证时间、获取数、收藏数。
  - 移除首页敏感链接提示块，敏感链接仍只在详情页按 mock 解锁状态展示。
- `热门求资源` 改为 `热门悬赏`。
- 移除首页底部 `最新上传` 区块，避免首页重新变成资源流堆叠。

## 7. 可能影响范围

- 影响首页信息架构、首页分类展示和首页资源卡片密度。
- 不影响资源详情 mock 解锁、上传资源、补链、求资源发布、收藏、赚积分、邀请页、充值页的已有逻辑。
- 不修改真实后端、支付、邀请、二级收益、提现、广告统计。

## 8. 需要 AI 测试官复核的事项

- 复核首页是否符合“积分经济入口”目标。
- 复核 `本地生活` 仅作为一级分类展示是否合规。
- 复核首页邀请和充值入口文案是否避免真实到账或无条件奖励误导。
- 复核移除 `最新上传` 后，首页内容密度是否更清爽。
