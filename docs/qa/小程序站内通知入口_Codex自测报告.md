# 小程序站内通知入口_Codex自测报告

## 1. 本次修改目标

给小程序补上站内通知入口，让用户能看到后端已生成的收益、审核、资源状态通知，并能标记已读。

## 2. 修改文件列表

- video-ts/src/api/request.ts
- video-ts/src/types/index.d.ts
- video-ts/src/pages.json
- video-ts/src/pages/netdisk/mine.vue
- video-ts/src/pages/netdisk/notifications.vue

## 3. 核心实现说明

- 新增小程序通知列表接口和标记已读接口。
- 新增站内通知页面，展示未读数、通知列表、通知时间和详情弹窗。
- 我的页面新增“站内通知”入口，并显示未读角标。
- 未登录点击通知入口会先走现有登录拦截。

## 4. 已运行测试

## 5. 测试结果

- 小程序构建通过。
