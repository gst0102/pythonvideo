# PC后台资源质量运营闭环_测试清单与验收标准

## 功能核心目标

- 从运营看板资源质量榜进入资源质量详情页，查看投诉记录、恢复记录、解锁人数和最近处理日志。
- 质量榜支持筛选：全部、隐藏资源、高投诉、高解锁。
- 看板待处理区域展示自动预警：投诉达到阈值、短时间高解锁且高投诉。
- 质量榜统计改为后端聚合查询，避免资源量增长后逐条查询变慢。

## 关键风险点

- P0：质量详情里的解锁人数、投诉数、日志记录与后台流水/投诉/日志表不一致，导致运营误判。
- P0：新增查询影响资源解锁扣分、审核通过、投诉确认等核心积分/审核流程。
- P1：预警误报或漏报，导致运营忽略高风险资源。
- P1：筛选条件前后端口径不一致，隐藏资源、高投诉、高解锁展示错误。
- P2：详情页空状态、长标题、长备注展示不清楚。

## 验收标准

- 看板质量榜可按全部、隐藏、高投诉、高解锁切换。
- 点击质量榜资源能进入详情页。
- 详情页能看到投诉记录、恢复记录、解锁统计和最近处理日志。
- 看板今日待处理区域能提示高投诉和高解锁高投诉资源。
- 后端质量榜使用聚合查询或等价方案，避免逐资源循环查询。
- 构建和基础接口验证通过。
