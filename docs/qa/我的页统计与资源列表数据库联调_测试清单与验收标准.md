# 我的页统计与资源列表数据库联调 测试清单与验收标准

## 功能核心目标

- 我的页收藏数、上传数、补链数、今日可赚从后端读取。
- 资源列表从真实数据库资源表查询，支持筛选、排序、分页、加载更多。
- 未解锁资源继续隐藏网盘链接、提取码、解压码。

## P0/P1/P2 风险

| 风险 | 优先级 | 说明 |
|---|---|---|
| 未解锁接口泄露链接或提取码 | P0 | 会破坏积分解锁闭环 |
| 解锁/收藏因资源来源切换后找不到资源 | P0 | 核心流程中断 |
| 我的页统计显示假数据或与后端不一致 | P1 | 影响用户信任和运营判断 |
| 分页重复、漏数据或 has_more 错误 | P1 | 资源变多后列表不可用 |
| 筛选组合为空时缺少空状态 | P2 | 影响体验但不影响资金积分 |

## 验收标准

- P0 项必须全部通过。
- 资源列表默认和筛选请求必须由后端返回分页结构。
- 未解锁访问不得返回真实网盘链接、提取码、解压码。
- 我的页接口必须返回 `netdisk_stats`。
- 小程序类型检查和本地构建必须通过。
- 高频切页和重复筛选应优先使用本地短时缓存。
