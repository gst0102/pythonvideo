# 当前项目测试清单与验收标准

## 1. 功能核心目标总结

### 1.1 测试目标

基于 `d:\Desktop\vedo-project\myproject\docs\yuexiang-stage2-docs` 当前阶段文档，确认“悦享互动宝” MVP v0.1 是否已经形成以下最小业务闭环：

1. 用户可通过微信静默登录进入小程序，无需先授权头像昵称。
2. 用户可完成每日签到并获得积分，且同一天不能重复发放。
3. 用户可在互动任务中心完成小游戏任务并获得积分，且同一局不能重复结算。
4. 用户可通过激励广告获得签到加成或游戏加成，广告事件必须幂等。
5. 用户可看到统一积分资产、会员权益、邀请关系、提现入口与记录。
6. 用户可完成影视资源浏览、资源复制、视频解析与失败兜底流程。
7. 邀请奖励、一级返利、二级分销、冻结期、提现规则与积分流水保持一致。
8. 广告曝光、点击、完成、奖励发放、关键页面访问等事件可追踪、可审计。

### 1.2 测试范围

本次测试覆盖：

1. 微信静默登录与 token 鉴权
2. 首页今日福利卡、签到入口、视频解析与失败兜底
3. 签到、连续签到、广告加成
4. 互动任务中心、石头剪刀布、任务次数限制、会员差异
5. 我的页面积分资产、积分明细、提现申请与提现记录
6. 会员页面价格、权益、状态生效
7. 邀请绑定、邀请进度、一级返利、二级分销、冻结积分
8. 影视页资源浏览、搜索、复制、权益校验
9. 视频下载/解析流程与失败兜底
10. 埋点、事件日志、账务流水一致性

### 1.3 不在本轮强制验收范围

1. 独立重度小游戏
2. 复杂积分商城
3. 自动大额提现
4. 完整后台运营看板
5. 承诺收益类前台话术

## 2. P0/P1/P2 风险分级说明

- `P0`：不测可能导致积分、收益、返利、支付、广告统计、核心路径、数据一致性事故。
- `P1`：影响重要用户体验、转化路径或关键页面可用性。
- `P2`：轻微展示、文案、低频边界问题。

## 4. P0 高风险清单

以下问题必须按 `P0` 处理，未验证通过前不得给出“通过”结论：

1. 积分重复发放：签到重复、同局游戏重复结算、广告回调重复、支付回调重复。
2. 积分漏发：签到成功未到账、游戏完成未到账、返利应发未发、提现驳回未退回。
3. 积分流水和账户汇总不一致：`points_ledger`、`user_accounts`、前端资产页不一致。
4. 邀请关系错误：用户自己邀请自己、重复绑定上级、绑定错人。
5. 一级邀请奖励和二级分销比例错误：50%/5% 返利计算错误或发放对象错误。
6. 冻结积分逻辑错误：返利应冻结未冻结，或冻结期后无法解冻。
7. 广告统计严重错误：广告展示、完成、奖励发放记录不一致；多广告 ID 限次失效。
8. 支付/返利链路错误：支付成功未开通会员、支付失败却发奖励、重复回调导致重复返利。
9. 提现链路错误：未达到门槛仍可提现、提现申请未冻结积分、驳回未退回积分。
10. 前后台数据明显不一致：页面显示、接口返回、数据库记录三方不一致。
11. 刷收益风险：通过刷新、重复点击、重放请求、伪造事件 ID 刷积分或刷返利。
12. 高风险文案问题：出现“稳赚”“回本”“看广告赚钱”等收益承诺表达。

## 5. 验收标准

### 5.1 通过前必须满足

1. 微信静默登录成功，且新用户可自动建档。
2. 首页、影视、任务、我的四个 Tab 可正常进入。
3. 签到、任务结算、广告加成、会员开通、邀请绑定、提现申请主路径可用。
4. 所有积分变化都有流水，且流水与账户汇总一致。
5. 同一天签到不能重复发分；同一 `round_id` 和同一 `ad_event_id` 不能重复奖励。
6. 普通用户与会员用户的任务次数、签到奖励、提现门槛、影视权益差异正确生效。
7. 一级返利、二级分销、冻结积分逻辑正确。
8. 支付成功、支付重复回调、退款回滚场景规则清晰且结果正确。
9. 广告事件、关键页面访问、关键行为埋点可追踪。
10. 前台文案无高风险收益承诺。

### 5.2 默认不能判定为通过的情况

1. 任一 P0 测试项未覆盖。
2. 积分、返利、提现、支付、广告统计存在未解释差异。
3. 发现可复现的重复奖励问题。
4. 核心流水或埋点缺失，导致无法审计。

## 6. 回归测试清单

每次开发完成或 Bug 修复后，至少回归以下内容：

1. 新用户静默登录、自动建档、邀请码绑定。
2. 老用户登录后首页首屏今日福利卡展示。
3. 每日签到成功、重复签到拦截、会员签到差异。
4. 签到广告加成只发一次。
5. 游戏任务正常结算、重复 `round_id` 拦截、任务次数用尽后拦截。
6. 普通用户与月卡/季卡/年卡用户任务上限差异。
7. 游戏广告加成、广告事件幂等、多广告 ID 轮换。
8. 我的页面积分资产、积分明细、冻结积分、可提现积分展示。
9. 提现申请、驳回退回、待审核状态展示。
10. 会员开通后权益即时生效，重复支付回调不重复发放。
11. 邀请绑定、自邀拦截、重复绑定拦截、邀请进度展示。
12. 一级返利、二级分销、冻结期记录与解冻逻辑。
13. 影视资源浏览、复制权限校验、会员权益生效。
14. 视频解析成功路径与失败兜底路径。
15. 关键埋点与日志记录完整。
16. 页面文案与按钮文案无收益承诺和误导性表达。

## 7. 上线验收清单

上线前必须逐项确认：

1. 小程序可正常启动，四个 Tab 无白屏、无阻断性报错。
2. 微信静默登录链路可用，`AppSecret` 和 `session_key` 未暴露到前端。
3. 积分汇总、积分流水、页面展示三方一致。
