# 互动宝小程序与 H5 改造_测试清单与验收标准

## 测试目标

验证小程序已从“网盘资源解锁”前台形态收敛为“互动宝助手”，需求悬赏采用审核后进广场，H5 独立轻量详情页可独立访问且不依赖小程序 WebView。

## P0/P1/P2 风险

- P0：需求发布后积分未冻结、重复冻结、拒绝/取消/过期未退回、采纳重复发放。
- P0：小程序公开页仍直接展示网盘链接、提取码、解压码、收益、提现、二级分销主入口。
- P1：后台审核状态和小程序需求广场展示不一致。
- P1：H5 详情页无法打开，或小程序复制链接域名配置不生效。
- P2：文案残留“资源库/解锁”等旧表达，但不影响主流程。

## 验收标准

- P0 测试项全部通过后，才可进入人工真机确认。
- 小程序公开主路径不得直接出现高风险访问字段或收益提现入口。
- 积分冻结、退回、发放必须有流水且幂等。
- 本地构建通过不等于线上生效；上线前必须确认后端部署、H5 部署、小程序上传和真机新包。
