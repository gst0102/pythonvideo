# 积分质量策略v0.2_Codex自测报告

## 1. 本次修改目标

- 落地积分质量策略 v0.2 的 MVP 版本。
- 支持新用户注册送 100 积分。
- 支持上传奖励分期、资源解锁分账、平台积分回收统计、信用/贡献排序。
- 支持确认失效后的扣分、降信用和负积分限制。
- 支持上传资源有效满 7 天后定时释放后段奖励。
- 支持小程序积分明细页展示新增积分流水类型。
- 支持信用分在我的页和资源卡片上展示，并说明信用恢复方式。

## 3. 核心实现说明

- 新增 `user_quality_profiles`，记录信用分、贡献值、短期失效次数和风控等级。
- `netdisk_resources` 增加上传者、质量分、投诉数、失效数、长期有效奖励字段。
- `netdisk_uploads` 增加已释放奖励和 7 天奖励状态字段。
- 新用户首次正式微信登录发放 100 可用积分。
- 新增后台直接确认资源失效接口：`POST /admin/netdisk/resources/{resource_id}/confirm-invalid`。
- 上传提交不再立即发冻结分；审核通过发放首段 2 分。
- 新增 7 天有效奖励释放逻辑：审核通过资源持续有效满 7 天后补发 3 分，写入 `upload_reward_valid_7d` 流水，并同步上传记录、资源长期有效状态、信用/贡献记录。
- 新增后台手动释放接口：`POST /admin/netdisk/uploads/release-valid-7d-rewards`，用于联调、补偿和运营手动触发。
- 新增 APScheduler 定时任务 `netdisk_valid_7d_upload_rewards`，默认每日 03:35 执行，可通过 `NETDISK_VALID_REWARD_CRON_HOUR` / `NETDISK_VALID_REWARD_CRON_MINUTE` 调整。
- 资源首次解锁后：
  - 普通资源上传者得 1 分。
  - 精选资源上传者得 2 分。
  - 官方资源平台回收全部。
  - 上传者单资源每日分成上限 10 分。
- 资源确认失效后按上线时长扣分、降信用，并允许可用积分变成负数。
- 资源 `hot/recommend/featured` 排序使用质量分、下载、收藏和最近验证时间。
- 小程序资源列表展示“优质上传者/长期有效”等轻量标签，我的上传展示已到账和待 7 天有效奖励。
- 小程序新增积分明细页 `/pages/points/ledger`，展示可用积分余额、收入/消耗/处罚/平台回收/信用调整等流水，并从“我的页”形成入口闭环。
- 用户资料接口返回信用分、贡献值、信用等级、风控等级和恢复提示。
- 小程序我的页已替换为商业化新版结构，保留总积分主视觉，信用分作为辅助信号展示。
- 资源卡片展示上传者信用分，如“上传信用103分”，并继续显示高信用/优质上传者标签。
