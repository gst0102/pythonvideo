# PC后台网盘运营后台重做_测试清单与验收标准

## 功能核心目标

将 PC 后台收敛为悦享资源库运营后台，支持运营看板、审核中心、资源库、风控待追缴、规则配置，并保证积分统计口径与后端流水一致。

## P0/P1/P2 风险

| 风险 | 级别 | 说明 |
|---|---|---|
| 今日积分发放/消耗统计与 `points_ledger` 不一致 | P0 | 会影响管理员对积分池健康判断 |
| 审核通过、拒绝、确认失效导致重复释放或重复扣分 | P0 | 涉及积分资产一致性 |
| 待追缴金额统计错误 | P0 | 会影响风控处理 |
| 后台操作失败只显示 400/500 | P1 | 影响运营定位问题 |
| 删除旧页面后路由仍引用旧文件 | P1 | 会导致构建或页面访问失败 |
| 后端未启动时前端提示不清楚 | P2 | 本地验收体验问题 |

## 验收标准

- P0 用例全部通过。
- PC 后台只保留网盘运营相关入口。
- 后台操作失败展示中文业务原因。
- 小程序端不受影响。
