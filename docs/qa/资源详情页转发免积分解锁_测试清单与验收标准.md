# 资源详情页转发免积分解锁_测试清单与验收标准

## 1. 功能核心目标

资源详情页新增“转发好友免积分”按钮，与“获取网盘信息”同一行展示。用户转发资源给好友后，发起人和通过该分享链接进入的好友，都可以免积分、免广告获取该资源网盘信息；后端必须真实记录 0 分解锁流水，不能只做前端展示。

## 2. 测试范围

- 小程序资源详情页按钮、分享路径、登录提示、自动领取。
- 后端分享 token、分享解锁、好友领取解锁接口。
- 积分账户余额、积分流水、获取历史、资源链接返回。
- 原普通扣积分解锁流程回归。

## 3. P0/P1/P2 风险

- P0：分享解锁错误扣积分或余额变化。
- P0：好友通过分享领取后未写流水，导致获取历史和已解锁状态不一致。
- P0：同一用户重复点击分享/重复领取导致重复写流水或重复增加下载数。
- P0：伪造分享参数可免积分解锁任意资源。
- P1：未登录好友打开分享页没有明确登录领取路径。
- P1：普通“获取网盘信息”被新逻辑影响，不能正常扣积分解锁。
- P2：按钮文案、布局在小屏幕拥挤。

## 5. 验收标准

- 发起人和分享链接进入的好友均可免积分、免广告获取网盘信息。
- 后端返回真实链接前必须完成合法 token 校验和 0 分解锁流水记录。
- 用户积分余额、可用积分、消耗积分不因分享解锁变化。
- 同一用户同一资源只能生成一次有效解锁记录。
- 普通扣积分解锁流程不受影响。

## 6. 自动化建议

- 在 `scripts/verify_netdisk_unlock_flow.py` 增加分享免积分链路断言。
- 增加接口测试：`share-token`、`share-unlock`、`share-claim`、篡改 token、重复领取。
- 小程序端建议补真机/开发者工具用例，确认分享成功回调能触发发起人解锁。

## 7. 回归范围

- 资源详情解锁、复制链接、追更订阅。
- 获取历史。
- 积分明细和账户余额。
- 邀请参数透传。
- 微信分享路径和登录重定向。
