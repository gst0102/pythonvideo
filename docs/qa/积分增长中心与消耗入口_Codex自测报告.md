# 积分增长中心与消耗入口_Codex自测报告

生成日期：2026-06-11
执行角色：开发 Codex

## 1. 本次修改目标

将网盘资源互助 MVP 的 `赚积分` 页从普通任务列表升级为积分经济中心，补齐积分产生、邀请增长、充值入口和积分消耗规则展示。

本轮仍为静态原型，不接真实后端、不发起微信支付、不真实增加积分、不真实扣减积分、不冻结真实悬赏积分。

## 3. 核心实现说明

- 赚积分页升级为“积分经济中心”：
  - 顶部展示当前积分、今日已赚 `6/60`。
  - 首屏展示 `充值积分` 和 `邀请好友` 两个主入口。
  - 任务拆分为 `高收益任务` 和 `每日任务`。
  - 增加 `积分可以用来做什么` 消耗场景模块。

- 邀请规则 mock：
  - 好友注册 `+5分`。
  - 好友首次获取资源 `+10分`。
  - 好友首次充值 `+20分`。
  - 单个有效邀请最高 `+35分`。
  - 每日邀请奖励上限 `50分`。

- 充值规则 mock：
  - MVP 仅展示 `10元 = 100积分`。
  - 点击 `模拟充值` 只展示 toast，不发起真实支付。

- 积分消耗场景 mock：
  - 普通资源 `-5分`。
  - 精选资源 `-10分`。
  - 官方合集 `-20分`。
  - 发布求资源悬赏冻结 `5-50分`。
  - 置顶求资源 `-10分`。
  - 加急求资源 `-20分`。
  - 查看热门榜单 `-5分`。
  - 美食探店合集 `-5到-10分`。
  - 下载资料合集 `-10到-20分`。
