# 补链投诉数据库联调与收藏数口径 测试清单与验收标准

## 功能目标

- 补链/投诉提交进入真实数据库。
- 支持全部补链/投诉列表和我的补链/投诉记录。
- 我的页补链数从后端统计读取。
- 收藏/取消收藏后资源收藏数同步变化。

## 验收标准

- 补链/投诉必须真实入库。
- 我的补链/投诉记录必须按用户隔离。
- 我的页补链数必须读取后端统计。
- 收藏/取消收藏后资源详情返回的收藏数必须同步增减。
- 发布求资源、上传资源、提交补链不得直接产生积分流水。
- 前端不得把待审核提交直接标成已完成任务。
- 小程序类型检查和本地构建必须通过。
