# 2026-05-31 工作日志

## 小红书视频下载 400 错误排查与修复

### 问题
服务器上小红书视频下载返回 400 Bad Request（本地正常）。

### 根因分析
1. **主要嫌疑**：服务器 IP（81.70.84.35 腾讯云）被小红书风控拦截。`xhs_service.py` 中短链接解析和 API 请求均为直连，无代理支持。
2. **次要嫌疑**：Cookie 可能从服务器 IP 被重新校验失效。
3. **第三嫌疑**：`cookies.txt.dan` 在项目目录中不存在，Docker 挂载时会创建空目录，导致代码读取异常。

### 修改内容

**core/xhs_service.py**：
- 添加 `_build_proxies()` 和 `_build_session()` 工具函数，支持通过 `PROXY_URL` 环境变量为所有 HTTP 请求走代理
- `resolve_short_link()` 改用 `_build_session()` 发请求
- `extract_stream_info()` 日志中输出代理状态、cookie 来源
- yt-dlp 选项中也传入 `proxy`
- `_extract_via_api()` 改用 `_build_session()`，增强错误日志（打印 HTTP 状态码、响应内容、字段缺失信息）
- `resolve_cookie_file()` 增加目录检测（防止 Docker 挂载缺失文件变成目录）

**core/video_service.py**：
- `get_ytdlp_options()` 中如果配置了 `PROXY_URL`，也传给 yt-dlp
- `resolve_cookie_file()` 同样增加目录检测

**controllers/video.py**：
- `ValueError` 异常处理增加 `exc_info=True`，打印完整异常栈

**docker-compose.yml**：
- 添加 `PROXY_URL` 和 `COOKIE_FILE` 环境变量注入
- `cookies.txt.dan` 挂载改为 `ro` 模式

**.env**：
- 添加 `PROXY_URL=` 配置项（默认为空）

### 第二次修复：user_id 空值 400 错误
- 前端传 `"user_id": ""` 时 Pydantic 默认值不生效，导致校验失败
- `VideoRequest` 新增 `normalize_user_id` validator，空值自动替换为 `"anonymous"`
- 本地实测小红书+抖音链接均下载成功
- Git commit `7811cbf`，已推送 `pythonvideo/master`

### 后续操作建议
1. 在服务器上 `git pull`，然后设置 `PROXY_URL` 代理地址
2. 重新部署：`docker-compose down && docker-compose up -d --build`
3. 查看容器日志：`docker logs -f video-service-app | grep XHS`

## 抖音视频解析 cookie 过期排查与修复

### 问题
服务器上抖音解析全部失败，错误 `Fresh cookies needed`。

### 排查过程
1. **本地测试 yt-dlp + cookies** → ❌ 失败（cookie 过期，yt-dlp 提取器要求极严）
2. **本地测试 DouyinService (Playwright)** → ✅ 成功（新 cookie 生效）
3. **服务器 Docker 测试 Chromium** → ✅ 可用（`playwright.chromium.launch` 正常，网络通）
4. **服务器 DouyinService** → ❌ 失败（`Unable to extract douyin video url`）
   - Playwright 能打开页面，但 DOM 提取策略（RENDER_DATA / SSR_HYDRATION / script tag）全部失败
   - 怀疑 Docker 环境中页面结构/重定向与本地有差异

### 修改内容

**core/douyin_service.py**：
- Chromium 启动参数新增 `--disable-dev-shm-usage` 和 `--disable-gpu`（Docker 兼容）
- **新增 API 拦截策略**（最高优先级）：拦截 `aweme/v1/web/aweme/detail` 响应，直接解析 JSON 获取视频 URL/标题/封面
- 提取优先级改为：API 拦截 → 网络流捕获 → DOM 提取
- 等待轮数从 8 秒增加到 10 秒

### 后续操作
1. 将 `douyin_service.py` 同步到服务器 `/opt/pythonvideo/core/douyin_service.py`
2. `.env` 中 `PROXY_URL=` 清空（代理已失效）
